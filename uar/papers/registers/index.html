Vision Transformers Need Registers

An interactive field guide

Why do some image positions become global scratch space? Follow the evidence, then trace the added tokens.

Before this article: ViT · Semantic representations

What was already possible

Section titled “What was already possible”

A patch token can stop behaving like a patch

Section titled “A patch token can stop behaving like a patch”

A ViT starts with one vector per image patch. After attention, each vector can contain information from the whole image. A grid-shaped output therefore does not guarantee that every position preserves its original local pixels. CLS is a separate learned readout token. A register is another learned input vector, intended to provide internal workspace.

DINO learns visual representations by matching teacher and student predictions across image views. CLIP-style methods align images with text; DeiT uses class labels. Registers are an architectural addition that the paper studies across these training objectives. They are not a new self-supervised loss or a quantization codebook.

The evidence behind the workspace hypothesis

Section titled “The evidence behind the workspace hypothesis”

The paper finds a small set of high-norm output patch vectors. In the analyzed DINOv2-g case, 2.37% exceed a chosen norm threshold of 150. This threshold is a diagnostic choice for that model. It is not a universal detector. The outliers often correspond to locally redundant background patches.

Linear probes provide two separate observations: outlier tokens recover local position and pixels less well, but predict image-level labels better than ordinary patches. The authors interpret this as reuse of spatial positions for global computation. This is an explanation supported by experiments, not a proof that every large-norm vector is harmful.

Norm and attention are different quantities. Q/K projections, normalization and vector direction also affect attention. Smooth feature maps and better task scores must be checked separately.

Insert learned registers into the shared encoder

Section titled “Insert learned registers into the shared encoder”

Let N be the number of patches, D the feature width and R the number of registers. The input has N+R+1 positions. Register initial values are shared across images, but their activations change with each image through attention. The same Transformer blocks process CLS, registers and patches together.

In the pinned DINOv2 code, absolute positions are first added to CLS and patches. Registers are then inserted after CLS. The paper figure draws a different token order; the code order is used in this walkthrough. Existing memory-token work already supplied the general mechanism. This paper adds the visual diagnosis and controlled evidence for this remedy.

Section titled “Discard workspace outputs, not image positions”

For 256 patches and four registers, the encoder processes 261 positions and returns the same 256-position image grid. Four width-768 input vectors add 3072 parameters. The attention-score matrix grows from 257² to 261² entries per head. This small calculation does not include projections, MLPs or hardware effects.

Training is not sampling

Section titled “Training is not sampling”

Train with the changed sequence; inspect the actual controls

Section titled “Train with the changed sequence; inspect the actual controls”

The experiments train models with registers. Appending untrained vectors to an existing checkpoint is not the reported procedure. The study uses DeiT-III ViT-B and DINOv2 ViT-L on ImageNet-22k, and OpenCLIP ViT-B/16 on a licensed Shutterstock image–text corpus. These are different training settings.

Most experiments use four registers; the count ablation includes 0, 1, 2, 4, 8 and 16. The appendix also enables antialiasing for DINOv2 position interpolation. A faithful comparison records this setting, the backbone size, training data, readout type and downstream protocol. A register-count slider cannot reproduce these training runs.

What this does not establish

Section titled “What this does not establish”

What this changes for reconstruction research

Section titled “What this changes for reconstruction research”

LOST object discovery improves for DINOv2 but becomes slightly worse for OpenCLIP in the reported comparison. Removing artifacts is therefore not a guarantee of universal gains. The local linear pixel probe is not a full image decoder. The paper does not establish that registers improve RAE reconstruction.

For UAR, first check which tokens the frozen encoder returns and which positions the decoder reads. Then test a matched encoder/decoder comparison if needed. Registers are not TiTok compressed latent slots: this design keeps the original patch grid and adds internal positions.
