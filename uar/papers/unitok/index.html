UniTok: split a code, share the representation

An interactive field guide

UniTok gives reconstruction and image-text alignment access to the same quantized representation.

Before this article: Semantic representations · VQ-VAE

What was already possible

Section titled “What was already possible”

A single small codebook can restrict how much detail and semantic information survive quantization. Reconstruction and contrastive objectives also put different demands on features. UniTok tests a joint training recipe with more flexible quantization, rather than assuming these demands are always incompatible.

Tools this method builds on

Section titled “Tools this method builds on”

Vector quantization (VQ) replaces a continuous feature by the nearest entry in a finite codebook. The stored index is discrete; the decoder receives the selected vector. A straight-through estimator supplies a training derivative across the hard choice.

Image–text contrastive learning makes matched image and caption embeddings more similar than mismatched pairs. It teaches a relation to text, not exact pixel recovery. A frozen text teacher anchors this relation but still contributes pretrained knowledge.

Residual quantization repeatedly quantizes the remaining feature error and sums the selected vectors. It differs from splitting channels into independent codebooks and from encoding separate spatial scales. Always identify which meaning of “multiple codes” a paper uses.

What changes, and why

Section titled “What changes, and why”

Multi-codebook quantization splits the channel vector into M sub-vectors. Each selects an entry from its own codebook; concatenate the selected vectors. This differs from residual quantization, which repeatedly quantizes the remaining error. UniTok uses a hybrid CNN/Transformer backbone and sends the quantized features to both reconstruction and image-text branches.

Do not confuse positions with code IDs

Section titled “Do not confuse positions with code IDs”

A single low-width code can discard information needed for semantics. UniTok divides each feature vector into M channel groups and quantizes each group with its own dictionary. It concatenates the selected vectors, projects them back to a useful feature width, and uses the result for both pixel reconstruction and text alignment. The backbone is a hybrid CNN/Transformer, not a strictly pure ViT.

Kᴹ is the number of possible combinations, not an allocated table of Kᴹ learned vectors. In the main setting, 256 positions each carry eight IDs from 4,096-entry codebooks. There are 2,048 IDs and 24,576 fixed-length bits per image, or 0.375 bpp at 256². Reporting only “256 tokens” omits most of the discrete payload.

Follow the upper path from the image encoder to channel groups, separate codebooks and the image decoder. The grouped codebooks quantize different parts of each position’s vector; they are not separate image crops. The lower text tower provides a contrastive target for the quantized image features.

Solid-color and hatched cells distinguish continuous and discrete representations. Reconstruction and contrastive losses read the shared quantized path. One spatial position can hold several code IDs, so position count is not the same as transmitted ID count.

Work through the mechanism

Section titled “Work through the mechanism”

For M codebooks of K entries, store M×K vectors but represent K^M combinations. The demo computes both quantities. Combinations are not an explicitly stored giant vocabulary. Each position requires M log₂K nominal bits when all sub-codes use fixed length.

The main configuration has 256 spatial positions, eight 4096-entry sub-codebooks, and eight dimensions per sub-vector. That is 2048 IDs, 64 latent channels, and 24576 nominal bits per image, or 0.375 bpp at 256². Calling these 256 visual tokens describes the spatial interface, not 256 individual codes.

What image–text contrastive learning asks for

Section titled “What image–text contrastive learning asks for”

For a batch of matched image–caption pairs, normalize pooled image and text embeddings and compare their similarities. A contrastive objective raises a matched pair’s similarity relative to other captions in that batch. It does not reconstruct every pixel, so the reconstruction objective remains necessary. Conversely, reconstructing a dog image does not by itself align the code with the word “dog.”

Temperature T changes how strongly the objective concentrates on high-scoring negatives. With two identical logits the matched probability is 1/2 and the loss is ln 2. If the matched logit exceeds the other by ln 3, its probability is 3/4. This explains the competition in one direction; a symmetric image–text objective also predicts images from text.

A spatial token can contain several predictions

Section titled “A spatial token can contain several predictions”

The multimodal language backbone can consume one combined visual embedding per spatial position. A depth Transformer then predicts the position’s subcode IDs sequentially. This avoids expanding every subcode into a full-length main-backbone token, but it introduces another autoregressive level. Capacity, sequence length and number of sampling steps must be counted separately.

p(k1:M∣h)=∏m=1Mp(km∣h,k<m)p(k_{1:M}\mid h)=\prod_{m=1}^{M}p(k_m\mid h,k_{<m})p(k1:M​∣h)=m=1∏M​p(km​∣h,k<m​)

The tokenizer loss and the multimodal language-model loss belong to different training stages. Tokenizer evidence can establish a reconstruction/alignment tradeoff; downstream VQA and image generation also depend on the language backbone, instruction data and output heads. The best zero-shot classification configuration need not give the best VQA result.

Core derivation

Section titled “Core derivation”

Each of M independent subspaces chooses one of K entries. The product rule gives K^M possible combinations; fixed-length coding needs log₂ of this count. The storage count for entries is only M×K.

Training is not sampling

Section titled “Training is not sampling”

Train reconstruction and image-text contrastive objectives jointly. For the multimodal model, merge sub-code embeddings at each spatial position into a main-sequence token. A depth Transformer predicts sub-codes inside that position. Tokenizer training and LLM adaptation remain separate stages. The main tokenizer data is DataComp-1B, not an ImageNet-only budget.

Audit the quantized branch and the training batches

Section titled “Audit the quantized branch and the training batches”

The pinned implementation sends quantized, reprojected features to both branches; encode_image is not a shortcut around quantization. Check each subcode index range and concatenate in the original order. Its vocab_size argument is the sum of entries across codebooks, then divided by the number of codebooks during construction. It is neither Kᴹ nor automatically K per subbook.

Reconstruction may use a sub-batch while contrastive training uses the full text–image batch. Verify reductions and distributed negatives before comparing loss weights. Check generator/discriminator gradient isolation. The paper’s billion-pair training and a small image-only adaptation have different data regimes. Keep initialization, released checkpoint version and the attention-projection change explicit.

What this does not establish

Section titled “What this does not establish”

The pretrained-initialization model has better zero-shot classification but does not lead every downstream VQA result. Keep initialization, data, and task protocol attached to each score. The current encoder includes convolutional spatial structure; an absent explicit position table would not make it position-free.

Check your understanding

Section titled “Check your understanding”
Are eight sub-codebooks equivalent to eight residual quantization stages?

No. MCQ quantizes different channel slices. RQ repeatedly quantizes the residual of the same vector.
