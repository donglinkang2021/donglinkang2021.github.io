DiT: a Transformer inside latent diffusion

An interactive field guide

DiT changes the denoising network. The original system still uses a VAE to convert between images and latents.

Before this article: Diffusion and flow matching · ViT · Variational autoencoders

What was already possible

Section titled “What was already possible”

Latent diffusion already reduced sampling cost by denoising a compressed image space. U-Nets provided the denoising backbone. DiT studies a scalable Transformer backbone in that role, with a controlled comparison of model size, patch size, and conditioning designs.

Tools this method builds on

Section titled “Tools this method builds on”

Flow matching trains a time-conditioned network to predict a velocity along a constructed data/noise path. Sampling integrates the learned field over several steps. A local squared-error target does not turn the final stochastic output into direct mean regression.

Self-attention computes a weighted mixture of token values from query–key similarities. A mask determines which tokens can contribute. Position encoding supplies geometry; a causal mask supplies an information boundary. These are separate design choices.

What changes, and why

Section titled “What changes, and why”

Patchify the noisy VAE latent, add fixed 2D sine-cosine positions, and process all positions with Transformer blocks. Timestep and class embeddings modulate normalization and residual gates through adaLN-Zero. Zero-initialized gates initially close residual branches. The output head predicts noise and variance terms, then unpatchifies the result.

Follow the image through two patch scales

Section titled “Follow the image through two patch scales”

The original DiT system first uses a pretrained VAE. A 256 × 256 image becomes a 32 × 32 × 4 latent. DiT patch size 2 groups each 2 × 2 latent region into one token, giving 16 × 16=256 Transformer positions. A linear projection maps each 16-value latent patch into the model width. The model later unpatchifies predicted outputs back to the latent grid.

These are different patch scales: VAE compression maps pixels to latent positions; DiT patchification groups latent positions. Reducing the DiT patch size increases denoiser computation without changing the VAE bottleneck. Calling the whole system a Transformer autoencoder hides the VAE that still performs pixel reconstruction.

Work through the mechanism

Section titled “Work through the mechanism”

For 256² pixels, a common VAE produces 32 × 32 × 4 latents. DiT patch size 2 gives 16 × 16 Transformer positions. These are patches of latents, not 2 × 2 RGB patches. One denoising call updates all noisy positions; it is not left-to-right autoregression.

The gate demo starts with α=0. Change the condition scale γ: the branch remains closed. Then increase α to let the condition affect the residual output. The example isolates gating, not full layer normalization or learned timestep embeddings.

The target is noise, not the class label or image

Section titled “The target is noise, not the class label or image”

A noise schedule defines how much signal remains at timestep t. Training draws a clean latent z₀, Gaussian noise ε and a timestep, then constructs zₜ. The network receives zₜ together with time and class conditions. An epsilon-prediction objective asks it to recover the noise realization that was added, not merely to predict a class. The original system also predicts a variance component for its diffusion objective.

When the signal coefficient is near one, the input is almost clean. When it is near zero, the input carries little evidence of the original sample and the class prior matters more. Sampling needs a solver or reverse process that repeatedly calls the network; one predicted noise tensor is not a finished image. The VAE decoder is applied after latent sampling.

adaLN-Zero: conditions control a residual update

Section titled “adaLN-Zero: conditions control a residual update”

LayerNorm standardizes a token’s channels. Adaptive LayerNorm then shifts and scales them using a condition vector built from time and class embeddings. A separate gate controls how strongly the branch changes the residual stream. The attention and MLP branches have their own modulation parameters.

u=(1+γ(c))LN⁡(h)+β(c),h+=h+g(c)F(u)u=(1+\gamma(c))\operatorname{LN}(h)+\beta(c),\qquad h^+=h+g(c)F(u)u=(1+γ(c))LN(h)+β(c),h+=h+g(c)F(u)

With gate g=0, a block begins as an identity map even if F has nonzero activations. Zero initialization of the modulation output makes this starting point explicit; it is not a rule that the network stays zero. If h=2, F(u)=3 and g=0.1, the update is 2.3. This toy scalar example explains the gate, not a trained DiT activation.

Training is not sampling

Section titled “Training is not sampling”

Train the denoiser on noisy latents from an existing VAE. During generation, sample a latent through repeated denoising calls, then call the VAE decoder for RGB. The decoder comparison in Appendix D uses the same encoder and DiT-XL/2 with CFG=1.5; it tests final generation quality, not tokenizer reconstruction.

Reproduction checks for the latent boundary

Section titled “Reproduction checks for the latent boundary”

Record the VAE checkpoint and latent scaling constant along with DiT weights. Check patchify/unpatchify inversion, fixed two-dimensional sin-cos positions, output channel count and class-dropout behavior. Original DiT uses full attention over current noisy positions; a causal language mask would change the model. Later DiT variants using RoPE do not change the original paper’s position scheme.

When comparing generated-image quality, record the sampler, number of network evaluations, guidance scale and VAE decoder. The paper’s decoder substitution experiment changes final generation FID even with the same latent generator. This shows that generation quality is a system measurement. A DiT result is not by itself evidence that the first-stage autoencoder reconstructs better.

What this does not establish

Section titled “What this does not establish”

Original DiT is not a replacement image tokenizer, and it does not use RoPE. To use a Transformer for reconstruction itself, supply the image code as a condition to a pixel denoiser, as FlowMo does. Check your understanding

Section titled “Check your understanding”
After DiT produces a clean latent, is the RGB image ready?

No. The VAE decoder must still map the latent to pixels.
