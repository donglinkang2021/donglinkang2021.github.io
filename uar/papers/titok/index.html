TiTok: a short sequence can describe an image

An interactive field guide

Flattening a grid keeps one token per location. TiTok instead learns a small set of global latent slots.

Before this article: ViT · VQGAN · Evaluation

What was already possible

Section titled “What was already possible”

VQGAN compresses images into a smaller spatial grid and quantizes each position. The grid gives a useful local structure, but its length is tied to resolution and downsampling. TiTok asks whether the bottleneck must retain this one-to-one spatial layout.

Tools this method builds on

Section titled “Tools this method builds on”

Vector quantization (VQ) replaces a continuous feature by the nearest entry in a finite codebook. The stored index is discrete; the decoder receives the selected vector. A straight-through estimator supplies a training derivative across the hard choice.

Self-attention computes a weighted mixture of token values from query–key similarities. A mask determines which tokens can contribute. Position encoding supplies geometry; a causal mask supplies an information boundary. These are separate design choices.

A rate–distortion tradeoff balances code length against reconstruction error. A shorter token sequence is not automatically a lower bit rate: codebook count, channel width and numeric precision also matter. Count the representation payload separately from encoder and decoder computation.

What changes, and why

Section titled “What changes, and why”

The encoder reads image patches together with K learned slots. Self-attention lets each slot gather information from the whole image. Only slot outputs pass through vector quantization. The decoder combines these quantized slots with position-bearing mask queries to recover a dense output. Slots have identities, but no fixed pixel neighborhoods.

Slots are a learned bottleneck

Section titled “Slots are a learned bottleneck”

Append K trainable slot vectors to the image patch sequence. Self-attention lets slots read patch information and communicate with one another. After encoding, discard the patch outputs and keep only the slot outputs. This discard operation enforces the interface: the decoder cannot recover discarded patch features through a hidden skip connection. Each retained slot is then quantized.

[Hx,Hs]=E([Xpatch;S]),Z=Q(Hs),∣Z∣=K[H_x,H_s]=E([X_{\rm patch};S]),\quad Z=Q(H_s),\quad |Z|=K[Hx​,Hs​]=E([Xpatch​;S]),Z=Q(Hs​),∣Z∣=K

For 256 image patches and 32 slots, the encoder initially processes 288 tokens, not 32. Only the downstream representation is short. A 4,096-entry codebook assigns 12 fixed-length bits per ID, so 32 IDs carry 384 bits before coding overhead. The decoder still has to construct all output positions. Short latent length does not make every training stage cheap.

Work through the mechanism

Section titled “Work through the mechanism”

Follow a 256² image: patch features enter the encoder, 32 latent vectors leave the bottleneck, and many output queries restore the spatial grid. More output queries do not mean more encoded information; they ask the same compact representation different spatial questions.

The demo retains global basis coefficients of a signal. Reduce their count and inspect the lost frequency. This illustrates a global bottleneck, but does not reproduce learned attention or TiTok quality. The paper compares different trained K settings, not this analytic threshold.

How 32 slots can return a full image

Section titled “How 32 slots can return a full image”

A decoder needs to know both what information is available and where to place the output. Quantized slots provide the first part. Mask queries with position embeddings provide output locations. The decoder mixes these streams and predicts a dense target. A query is not a missing original pixel value; it is a learned request for information at a location.

Y^=D([Z;M+Pout])query,Lproxy=−∑ilog⁡pθ(yiteacher∣Z)\hat Y=D([Z;M+P_{\rm out}])_{\rm query},\qquad L_{\rm proxy}=-\sum_i\log p_\theta(y_i^{\rm teacher}\mid Z)Y^=D([Z;M+Pout​])query​,Lproxy​=−i∑​logpθ​(yiteacher​∣Z)

In the original main recipe, targets are codes from an existing MaskGIT-VQGAN tokenizer. The resulting code representation is passed to an existing pixel decoder. This separates learning a compact representation from learning all pixel statistics from scratch. The proxy loss also imports the teacher’s representation choices and dependencies. A fully direct pixel decoder is a different configuration.

Training is not sampling

Section titled “Training is not sampling”

The original main recipe first predicts proxy codes from an existing MaskGIT-VQGAN. Its pixel decoder produces the image. A second stage freezes the encoder and quantizer while tuning the decoding path. A separate MaskGIT generates TiTok codes. Tokenizer reconstruction and code generation therefore have different objectives and costs.

Why decoder fine-tuning changes the result

Section titled “Why decoder fine-tuning changes the result”

After proxy training, freeze the encoder and quantizer and fine-tune the decoder side for image reconstruction. This keeps the discrete interface stable while improving the image map. If the encoder is allowed to drift, code meaning can change and the stage separation no longer matches this recipe. The L-32 ablation changes rFID from 5.48 before decoder fine-tuning to 2.21 after it under the reported setting; do not attribute that change solely to choosing 32 slots.

The audited code has separate learned positions for image patches and latent slots. Its legacy branch also changes latent reshape behavior. Verify slot order and channel layout against the checkpoint, then check that code IDs reproduce the same reconstruction as forward encoding. During decoder fine-tuning, assert that encoder, slot parameters and quantizer receive no updates.

Generation is another stage: a MaskGIT-style model predicts TiTok IDs. Tokenizer reconstruction needs one encoder and decoder path; generation additionally requires the latent sampling process. Report K, codebook size, tokenizer variant, decoder fine-tuning status and generator settings together. A 32-token reconstruction score and a 128-token generation score are not one configuration.

What this does not establish

Section titled “What this does not establish”

A Transformer tokenizer is not necessarily a CNN-free deployed decoder. The original recipe uses a proxy model and pixel decoder. The 32-token result must not be combined with the best generation result of the 128-token model. Shorter sampling sequences also do not establish cheaper tokenizer training.

Check your understanding

Section titled “Check your understanding”
Can every slot be assigned a fixed square in the image?

No. Its information is learned globally. Dense output queries, rather than latent slots, provide the reconstruction grid.
