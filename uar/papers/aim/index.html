AIM: predict patches to learn features

An interactive field guide

Continuous autoregression can be a pretraining task even when image generation is not the main evaluation.

Before this article: Attention and autoregression · ViT · Semantic representations

What was already possible

Section titled “What was already possible”

ViT normally reads all image patches to classify an image. Language models learn useful features by predicting the next token. AIM applies next-patch prediction to visual pretraining, using continuous pixels rather than a learned discrete image vocabulary.

What changes, and why

Section titled “What changes, and why”

Order patches in raster order and use causal attention. A per-patch MLP predicts normalized pixels of the next patch with squared error. Prefix attention lets an initial set of observed patches interact bidirectionally; only later patches carry the autoregressive target. This exposes the backbone to bidirectional context before downstream use.

Work through the mechanism

Section titled “Work through the mechanism”

Select causal mode in the demo. Row i can use keys up to i, and its output predicts the next patch. Switch to prefix mode: the first three positions can see one another, while later positions keep their causal boundary. Known prefix pixels are inputs, not targets that leaked backward from an unknown future.

With a fixed Gaussian output variance, minimizing squared error is equivalent up to constants to maximizing Gaussian conditional likelihood. When several futures are plausible, the best squared-error estimate can be their mean. This may still create useful features even if the mean patch looks poor.

Training is not sampling

Section titled “Training is not sampling”

After pretraining, discard the prediction head and evaluate the visual backbone. AIM uses an attentive probe with trainable attention pooling, so it is not a strict linear probe. The paper uses sinusoidal absolute positions at the input and before the prediction head.

What this does not establish

Section titled “What this does not establish”

The contribution concerns scalable representation learning. It does not show that direct L2 prediction is the best distribution model for photorealistic generation. MAR finding poor generation from direct L2 does not contradict AIM learning useful features with that objective.

Open the derivation

A Gaussian conditional with fixed variance has a log-likelihood whose mean-dependent term is squared error. Under squared error, the optimal predictor is the conditional mean. That explains why a point prediction may average incompatible futures.

Check your understanding

Section titled “Check your understanding”
Why is an attentive probe different from a linear probe?

Its trainable attention pooling changes how patch features are combined; a strict linear probe has only a linear readout over the specified fixed features.
