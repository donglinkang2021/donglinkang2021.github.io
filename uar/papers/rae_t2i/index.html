RAE-T2I: scale a shared feature space

An interactive field guide

A shared image representation can support separate understanding and generation paths. It need not imply one universal output head.

Before this article: RAE · Semantic representations · Diffusion and flow matching

What was already possible

Section titled “What was already possible”

The original RAE studies diffusion in pretrained feature spaces, including class-conditioned image generation. Text-to-image generation adds rich language conditions, larger data distributions, and demands such as rendering readable text. These can expose weaknesses that ImageNet reconstruction does not measure.

Tools this method builds on

Section titled “Tools this method builds on”

Freezing parameters stops their updates. It does not necessarily stop derivatives with respect to network inputs. A frozen feature extractor used on a reconstruction may still need an active input-gradient path; an encoder used only to supply fixed targets may run without that path.

LPIPS is a learned perceptual distance: compare normalized pretrained features, weight channel differences, and aggregate across positions and feature levels. In a reconstruction loss its parameters can stay frozen while gradients still pass through it to the reconstructed image.

A Gram matrix aggregates correlations between feature channels. Comparing Gram matrices emphasizes feature statistics and can ignore spatial permutations. It complements pixel and perceptual losses but cannot by itself enforce exact layout or character identity.

What changes, and why

Section titled “What changes, and why”

Freeze a SigLIP-2 So400M patch-14 encoder. At 224² input it gives 256 features of width 1152. Train a ViT image decoder. For generation, an LLM with learned queries and an MLP connector conditions a flow DiT. For understanding, another projector sends features from the same frozen encoder to the LLM. The representation is shared; the task heads differ.

Shared representation does not mean one task head

Section titled “Shared representation does not mean one task head”

This extension uses a frozen SigLIP-2 So400M patch-14 encoder. A 224² image gives 256 feature vectors of width 1,152. A ViT decoder maps them to pixels. For generation, a MetaQuery-style language model and learned queries feed an MLP connector and flow DiT. Understanding uses another projector from the shared image representation into the language model.

The image generation backbone remains diffusion/flow. The presence of a causal language model does not turn image feature generation into next-image-token causal AR. Trace which network outputs which variable: language context, query embeddings, denoised image features and final pixels are different interfaces.

Work through the mechanism

Section titled “Work through the mechanism”

The schedule demo uses m=256C and reference dimension n=4096. Set C=1152 and t=0.5: α=√72≈8.485 and shifted time is about 0.895. Under the data-at-zero convention, the shift places more probability on noisier training states. These arithmetic values illustrate the schedule, not a measured quality gain.

The decoder trains on about 73M examples, including web, synthetic, and text-rendering data. The paper finds that general web training alone is insufficient for reliable glyph recovery. A good natural-image rFID is therefore not a substitute for a dedicated text-reconstruction evaluation.

Compute the dimension-aware time shift

Section titled “Compute the dimension-aware time shift”

With N=256 and C=1,152, the representation contains 294,912 scalars. The reference dimension in the described shift is 4,096. The ratio is 72, giving α=√72≈8.49. This counts all feature values, not just the 256 visible positions.

α=NC/4096,t′=αt1+(α−1)t,t=12⇒t′=α1+α≈0.895\alpha=\sqrt{NC/4096},\qquad t^\prime=\frac{\alpha t}{1+(\alpha-1)t},\qquad t=\tfrac12\Rightarrow t^\prime=\frac{\alpha}{1+\alpha}\approx0.895α=NC/4096​,t′=1+(α−1)tαt​,t=21​⇒t′=1+αα​≈0.895

Endpoints remain zero and one, while intermediate times shift. Whether a larger t means more noise must be read together with the path convention. The numerical map alone does not tell you to reverse a solver or reuse another model’s schedule. The paper finds this adjustment important even when some small-model decoder tricks give less benefit at larger scale.

Why image reconstruction metrics miss typography

Section titled “Why image reconstruction metrics miss typography”

A semantic encoder can preserve the idea of a sign while losing exact character strokes. A decoder trained only on ordinary web images may not learn to recover those strokes reliably. The paper adds synthetic and text-rendered data to decoder training. This targets a data coverage problem, not merely a larger network or a new position embedding.

The decoder objective combines L1, LPIPS, Gram and adversarial terms. Pixel alignment, feature similarity, texture correlation and distributional realism are related but different constraints. Text-specific reconstruction should inspect character identity and layout, alongside aggregate metrics. Better ImageNet rFID is not sufficient evidence for faithful typography.

Core derivation

Section titled “Core derivation”

Training is not sampling

Section titled “Training is not sampling”

The decoder objective combines L1, LPIPS, Gram, and GAN terms. The generation study compares DiTs from 0.5B to 9.8B. Dimension-aware scheduling remains important, while some small-model improvements, such as a wide DDT head or decoder noise, become less useful at the larger text-to-image scale.

Keep the comparison and reproduction boundaries explicit

Section titled “Keep the comparison and reproduction boundaries explicit”

The paper’s fixed-256-token comparison uses different output resolutions for RAE and VAE, different latent widths and different pretrained encoders. Describe it as a system comparison at fixed sequence length. Do not claim equal bit rate, equal capacity or equal total pretraining cost. The reconstruction table does not show RAE winning every dataset.

Check patch-14 geometry, token selection, encoder normalization, latent statistics, query-to-DiT connector dimensions and the separate understanding projector. Keep decoder and generator checkpoints paired. The original RAE repository is not automatically the implementation of this extension; the existing reading did not audit an official extension commit.

Understanding scores from systems sharing the same frozen understanding encoder do not establish that generation training itself greatly improved understanding. Keep the causal claim aligned with what actually changed. Report decoder data, text-specific evaluation and total sampling cost alongside text-to-image quality.

What this does not establish

Section titled “What this does not establish”

The main comparison fixes 256 visual tokens, but RAE outputs 224² while VAE outputs 256²; feature width and pretraining cost also differ. This is a system comparison at fixed sequence length, not a completely matched rate/capacity study. Similar understanding results reflect the shared frozen understanding encoder, not proof that generation training caused a large understanding gain.

Check your understanding

Section titled “Check your understanding”
Does sharing the representation make this a continuous image-token causal AR model?

No. The image generator is still a diffusion/flow DiT. Representation sharing and generative factorization are separate design choices.
