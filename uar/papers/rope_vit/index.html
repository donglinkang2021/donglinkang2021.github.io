RoPE-ViT: position enters the comparison

An interactive field guide

Absolute position adds an address to a token. Rotary position changes how two tokens compare.

Before this article: ViT · Attention and autoregression

What was already possible

Section titled “What was already possible”

ViT adds learned absolute position embeddings at its input. RoPE was already used in sequence models to encode relative displacement through rotations of query and key vectors. RoPE-ViT studies how to extend this mechanism to two spatial axes.

Tools this method builds on

Section titled “Tools this method builds on”

Self-attention computes a weighted mixture of token values from query–key similarities. A mask determines which tokens can contribute. Position encoding supplies geometry; a causal mask supplies an information boundary. These are separate design choices.

  • Details: attention

What changes, and why

Section titled “What changes, and why”

Treat each pair of Q/K channels as a 2D vector. At position (x,y), rotate the pair by phase ωx x + ωy y. Axial RoPE assigns channel pairs to one axis at a time. Mixed RoPE lets a pair use both axes and learns the frequencies. This permits diagonal frequency directions directly. It does not mean axial Transformers cannot recognize diagonal objects.

A position operation inside attention

Section titled “A position operation inside attention”

RoPE splits a head’s channels into pairs and rotates each pair by an angle determined by position. Rotation preserves a vector’s length. More importantly, rotating a query and key converts their dot product into a function of the difference between their angles. This supplies relative position information without adding a position vector to the value stream.

Rϕ=[cos⁡ϕ−sin⁡ϕsin⁡ϕcos⁡ϕ],(Rϕpq)T(Rϕsk)=qTRϕs−ϕpkR_\phi=\begin{bmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{bmatrix},\qquad (R_{\phi_p}q)^T(R_{\phi_s}k)=q^TR_{\phi_s-\phi_p}kRϕ​=[cosϕsinϕ​−sinϕcosϕ​],(Rϕp​​q)T(Rϕs​​k)=qTRϕs​−ϕp​​k

The identity follows from Rᵀφ=R−φ and addition of rotation angles. If q=k=(1,0), the score becomes cos(φs−φp). A 0° difference gives 1, 90° gives 0, and 180° gives −1. In a real model, multiple channel pairs carry different frequencies and content vectors, so attention is not just one cosine of distance.

Work through the mechanism

Section titled “Work through the mechanism”

Both Q and K are rotated. Their dot product depends on the difference of their phases. Moving both positions by the same displacement cancels from that difference. Content still matters: the rotation does not replace the learned Q/K projections.

The demo keeps relative y displacement at 2 and changes relative x displacement and frequency direction. It shows one unit-frequency channel pair. A real head sums many channel pairs with different frequencies and content.

Axial versus mixed two-dimensional frequencies

Section titled “Axial versus mixed two-dimensional frequencies”

A vision token has two coordinates. Axial RoPE allocates channel pairs to x or y; each pair responds to one axis. Mixed RoPE assigns a two-component frequency vector to each pair, so its phase can respond to diagonal displacement too. This expands the phase basis. It does not mean an axial Transformer as a whole cannot recognize diagonal objects.

ϕj(x,y)=ωx,jx+ωy,jy,Δϕj=ωx,jΔx+ωy,jΔy\phi_j(x,y)=\omega_{x,j}x+\omega_{y,j}y,\quad \Delta\phi_j=\omega_{x,j}\Delta x+\omega_{y,j}\Delta yϕj​(x,y)=ωx,j​x+ωy,j​y,Δϕj​=ωx,j​Δx+ωy,j​Δy

For frequency (π/2,π/4), moving one patch right changes phase by π/2, while moving one patch down changes it by π/4. A joint move adds them. Increasing image size adds coordinates; it does not require interpolating a fixed position table for this rotary part. But larger positions can still lie outside the training distribution, so mathematical evaluability is not a guarantee of useful extrapolation.

Core derivation

Section titled “Core derivation”

A rotation matrix is orthogonal. Moving the rotation on Q through the transpose changes its sign. Two planar rotations add angles, so the result contains only their phase difference.

Rϕ(p)TRϕ(s)=R−ϕ(p)Rϕ(s)=Rϕ(s)−ϕ(p)R_{\phi(p)}^TR_{\phi(s)}=R_{-\phi(p)}R_{\phi(s)}=R_{\phi(s)-\phi(p)}Rϕ(p)T​Rϕ(s)​=R−ϕ(p)​Rϕ(s)​=Rϕ(s)−ϕ(p)​

For a linear coordinate phase, a shared translation cancels. This is a property of the rotary comparison, not proof that the full finite-image network is translation invariant.

Training is not sampling

Section titled “Training is not sampling”

The pinned implementation excludes the class token from rotation, uses float32 for frequency arithmetic, and keeps mixed frequencies trainable. RoPE acts inside attention at each layer. It can coexist with an absolute position table. The classification evidence below uses DeiT-III training for 400 epochs at 224².

Coordinate conventions are part of the model

Section titled “Coordinate conventions are part of the model”

The audited implementation excludes CLS from rotation. It uses x=index mod width and y=floor(index/width). Learned mixed frequencies are excluded from weight decay; frequency arithmetic uses float32 before returning to the attention dtype. Preserve the channel-pair ordering and head dimensions when loading weights. A different pairing can silently change every attention score while leaving shapes valid.

Test norm preservation and the relative-angle identity with small vectors. Test rectangular grids with the same area, such as 2 × 6 and 3 × 4: a cache keyed only by token count can return the wrong coordinates. Rebuild coordinate caches for shape or device changes, and avoid reusing cached learned phases after frequency parameters change.

The evidence here concerns recognition and dense prediction. It does not directly establish better reconstruction. For a reconstruction ablation, keep tokenizer, data and training budget fixed while changing position encoding. Do not reshape unanchored TiTok slots into an invented square grid merely to apply two-dimensional RoPE.

What this does not establish

Section titled “What this does not establish”

Resolution extrapolation on classification does not establish better reconstruction or text rendering. Also, grid shape matters: equal token counts do not imply equal coordinates. A rectangular-grid implementation must invalidate position caches when height or width changes. Unanchored TiTok slots do not acquire 2D coordinates just because their count is a square.

Check your understanding

Section titled “Check your understanding”
Why rotate both Q and K?

Their paired rotations make the comparison depend on phase difference. Rotating only Q leaves an absolute phase dependence.
