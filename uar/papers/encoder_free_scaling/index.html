Encoder-Free Multimodal Scaling

An interactive field guide

If pixels enter the language decoder directly, where does the visual work go—and when might the extra training cost disappear?

Before this article: ViT · CLIP and SigLIP series · Visual tokenizers in multimodal models

What was already possible

Section titled “What was already possible”

What does removing an encoder actually remove?

Section titled “What does removing an encoder actually remove?”

Reading: Lin Chen et al., “How Far Are We from Removing the Visual Encoder? Scaling Laws for Encoder-Free Multimodal Pretraining”, arXiv:2609.35457v1, 28 September 2026. The explanation covers the main text and Appendices A–G.

A visual encoder turns image patches into contextual representations before the language decoder sees them. Its pretrained weights supply a visual prior. Encoder-free models keep an input projection, but move representation learning into the decoder. They do not remove visual computation.

This paper asks how that change affects compute allocation. Does an extra unit of budget belong in a larger decoder or in more training tokens? The evidence comes from controlled pretraining sweeps, not from comparing unrelated flagship systems.

Read the result in two parts. Within the measured range, the encoder-free multimodal frontier is worse. Its fitted improvement is faster, which supports a conditional prediction of eventual parity. The second statement is not an observed crossover.

  • Paper: §1 — 2609.35457v1

A matched decoder ladder, a fixed-size visual encoder

Section titled “A matched decoder ladder, a fixed-size visual encoder”

Both families use 11 sparse MoE decoder sizes: 1.1B–44B total and 71M–2.4B active non-embedding parameters. The first layer is dense. Subsequent layers have 256 routed experts, top-8 activation and one shared expert. Both use RMSNorm and RoPE. Total parameters and active parameters describe different costs.

The pixels, preprocessing, data mixture and decoder visual-token count match. One visual token covers a 32×32 pixel region. The pretrained SigLIP 2 encoder is roughly 400M parameters: 27 layers, width 1152, patch size 16 and AnyRes. Its weights are trained jointly with the decoder; only its architecture stays fixed across the ladder.

The study therefore isolates decoder scaling with a fixed-size visual prior. It does not optimize encoder size and decoder size together. The main mask also differs between families; a causal encoder-free ablation checks whether the allocation shift survives this change.

From pretrained visual features to decoder tokens

Section titled “From pretrained visual features to decoder tokens”

For a preprocessed image grid of height H and width W divisible by 32, the ViT first produces HW/256 patch features at width 1152. A 2×2 ConvPool adapter reduces the spatial token count by four. A projector maps the result to decoder width d. Every decoder token then uses causal attention. The ViT has already mixed information bidirectionally inside the image.

Raw pixels still need a trainable front end

Section titled “Raw pixels still need a trainable front end”

The encoder-free branch groups four neighboring 16×16 raw patches into one 32×32 region. Each region contains 3072 scalar pixel values. LayerNorm → linear → LayerNorm transforms that vector; learned row and column embeddings add spatial position. LayerNorm → RMSNorm → linear then maps to the decoder width. The paper does not specify every intermediate width, so h below remains symbolic.

This adapts the Gemma 4 12B Unified input recipe, but changes its 3×3 patch merging to 2×2 for the comparison. Copying the original 48×48 token footprint would break the matched token count. For multiple AnyRes grids, apply this shape reasoning to each prepared grid.

X∈RN×3072→U∈RN×h,Ur,c←Ur,c+er+ec→Z∈RN×dX\in\mathbb R^{N\times3072}\to U\in\mathbb R^{N\times h},\quad U_{r,c}\leftarrow U_{r,c}+e_r+e_c\to Z\in\mathbb R^{N\times d}X∈RN×3072→U∈RN×h,Ur,c​←Ur,c​+er​+ec​→Z∈RN×d
pixels = merge_2x2(raw_patches_16(image))
u = ln2(linear1(ln1(pixels)))
u = u + row_position + column_position
visual = linear2(rmsnorm(ln3(u)))
logits = decoder(interleave(text, visual), image_bidirectional_mask)

Section titled “Bidirectional inside an image; causal elsewhere”

A query can read an earlier key. In the encoder-free main setting it can also read a later key when both positions belong to the same image. This does not expose future text. Count what is processed, not just what is supervised

Section titled “Count what is processed, not just what is supervised”

C is objective-specific training FLOPs, M is decoder FLOPs per processed token and D is the processed token count. Visual positions are excluded from cross-entropy but included in multimodal D. Attention cost also depends on packed length and the mask, so equal token counts do not imply identical M. M is not the total MoE parameter count.

The main plots count decoder compute. Appendix C adds the current visual front-end training cost and preserves the qualitative allocation ordering. That addition does not price the historical SigLIP 2 pretraining. Neither convention establishes full lifecycle cost or measured hardware latency.

An IsoFLOP curve asks where one budget goes

Section titled “An IsoFLOP curve asks where one budget goes”

Hold C fixed, choose decoder scales M, and allocate D=C/M tokens to each. Too small a model leaves a capacity bottleneck; too large a model gets too few tokens. Fit validation loss as a quadratic in log M and use its minimum. Repeating this process across budgets gives allocation laws and a loss frontier. A fitted minimum is an estimate, not another training run.

Each objective uses six logarithmically spaced budgets. The text window is 2×10¹⁹–2×10²⁰ FLOPs; the multimodal window is 10²⁰–10²¹. Exponents describe growth within each model family. The normalized lab uses each family’s own value at the smallest budget as 1, so its lines cannot compare absolute model sizes.

Derive the optimum before interpreting the exponents

Section titled “Derive the optimum before interpreting the exponents”

For the separable approximation L=E+AM⁻ᵅ+BD⁻ᵝ, substitute D=C/M. Differentiate with respect to M. The stationary point balances the two marginal loss terms, not necessarily their raw magnitudes. Solving gives a=β/(α+β), b=α/(α+β) and γ=αβ/(α+β). The paper estimates allocation exponents from the IsoFLOP profiles; this derivation explains the model behind its overtraining analysis.

A larger multimodal a means more of a growing budget goes into decoder scale. It does not say “57% of all FLOPs buy parameters”. At ten times the budget, a=0.570 means about 3.72× the baseline M and 2.69× its D.

Equal loss, two different efficiency ratios

Section titled “Equal loss, two different efficiency ratios”

Use encoder-free as target and encoder-based as reference. EGᶜ compares the compute needed to reach the same loss; EGᴹ compares the selected FLOPs per token at that loss. A value below 1 is unfavorable to encoder-free. For example, EGᴹ=0.80 implies 1/0.80=1.25 times as many FLOPs per token, not 20% fewer parameters.

The crossover is beyond the main fitting window

Section titled “The crossover is beyond the main fitting window”

The main multimodal fit ends at 10²¹ FLOPs. Its predicted parity point is 6.1×10²¹ FLOPs. The table gives conditional central 80% bootstrap intervals, not a guarantee that a new run will cross inside them. The law must persist, the encoder size stays fixed, and both families share an irreducible loss floor.

Topic-level fits predict earlier parity on STEM and then Charts, with later parity on GUI, OCR and Caption. That is a forecast over validation topics. It is not evidence that all chart benchmarks already favor encoder-free.

More tokens at a fixed model size

Section titled “More tokens at a fixed model size”

Overtraining starts at a compute-optimal model for C_base, keeps M fixed and multiplies its token count by k. Actual compute is kC_base. Substitution into the separable loss gives a multiplier g(k) on the reducible loss. At fixed actual compute, write the multiplier as g(k)k^γ; forgetting this change of axis can reverse an efficiency interpretation.

The idealized derivation gives g(k)=[β+αk⁻ᵝ]/(α+β). The paper instead fits empirical multipliers while keeping E, K and γ fixed. At k=5 these are 0.645 for encoder-free and 0.692 for encoder-based. At the largest fitted budget, the reported multimodal EGᶜ changes from 0.62 to 0.52, and EGᴹ from 0.80 to 0.74. More tokens help loss, but do not erase the relative benefit of allocating more capacity to the encoder-free decoder.

Training signals and the decoding protocol

Section titled “Training signals and the decoding protocol”

Pretraining uses a 1:1 text/multimodal mixture, sequence length 4096, Muon and 2000 warmup steps. Batch size and learning rate vary by decoder scale, using an internal scaling rule; each paired comparison uses identical hyperparameters. The loss is next-text-token prediction. Visual tokens receive gradients through their influence on predicted text. These details do not provide a complete public reproduction recipe.

Downstream evaluation applies no additional training. All checkpoints share 3-shot examples and prompts. Each example uses at most 192 visual tokens, the query at most 768, and the full prompt at most 4096 tokens. Multiple-choice and yes/no tasks use highest answer likelihood; open answers use greedy decoding for up to 32 tokens, with no external OCR.

A loss drop and a visual-attention change

Section titled “A loss drop and a visual-attention change”

Figure 7 shows an initially slow encoder-free loss decline followed by a sharper drop. For the analyzed 8B model, layer-12 attention mass on visual tokens rises from 0.217 to 0.645 across the selected checkpoints. The authors hypothesize a feedback loop: weak visual features attract little attention, but useful features receive more learning signal. This is an interpretation of correlated measurements, not an isolated causal intervention.

Locate the computation without overclaiming its meaning

Section titled “Locate the computation without overclaiming its meaning”

Visual tokens diverge from their input representations earlier in the encoder-free decoder, while text trajectories remain similar. Figure 9 measures cosine similarity to layer 0, not semantic accuracy. Appendix E repeats the pattern at several depths. Expert-load probes in Figure 10 find stronger visual routing concentration when modalities are separated; the aggregate can hide it. A larger MaxVio does not identify what an expert represents.

The causal-mask ablation retains a multimodal model-allocation exponent of 0.557, compared with 0.570 for bidirectional image attention. It supports the allocation shift beyond a mask-only explanation. The reported causal-versus-bidirectional efficiency ratios use causal as the target, so their direction must not be confused with the encoder-free-versus-based ratios above.

What this does not establish

Section titled “What this does not establish”

Which assumptions can move the forecast?

Section titled “Which assumptions can move the forecast?”

The two fits share a floor E per objective. The fitted multimodal floor is 0.403, but six frontier points over one decade do not determine the true asymptote. Perturbing this floor by ±10% shifts the k=1 crossover to [4.8, 9.0]×10²¹ FLOPs. This is a sensitivity range, not a confidence interval. The conditional bootstrap uses 4000 paired residual resamples; for k=5 it keeps the already fitted overtraining multipliers fixed.

A held-out multimodal forecast over 2.5× compute has signed loss errors of −0.01% for encoder-free and +2.19% for encoder-based. This useful short-range check does not validate the more distant crossover. The fixed encoder, MoE topology, mixture and preprocessing also limit transfer to other settings. Jointly scaling the encoder is a different allocation problem.

Under full current-training compute accounting, Appendix C reports encoder-based exponents a=0.273 and γ=0.362. The authors do not fit a new numerical crossover under that convention. Do not mix that exponent with the decoder-only crossover and present the result as a measured total-cost threshold.

What this changes in a reading of visual tokenizers

Section titled “What this changes in a reading of visual tokenizers”

The result separates visual-token count from representation quality. Equal counts do not give equal visual priors. It also suggests that removing an encoder reallocates computation to decoder layers and experts. That is a reason to investigate architecture and allocation together, not a prescription to delete a working visual encoder at a small budget.

Check your understanding

Section titled “Check your understanding”
Does a predicted crossover near 10²² FLOPs mean encoder-free models already win?

No. The main multimodal fit stops at 10²¹ FLOPs, and parity is extrapolated under fixed encoder size and a shared loss floor. Downstream average scores still trail in the evaluated range.
