EOSTok: make prediction preserve the image

An interactive field guide

An easier token prediction problem is not always a better image model. The tokenizer could simply discard information.

Before this article: TiTok · Attention and autoregression · Semantic representations

What was already possible

Section titled “What was already possible”

Two-stage systems train the tokenizer first, then train an autoregressive prior over fixed codes. End-to-end training could coordinate them, but a next-token loss alone rewards predictability. A collapsing or smaller effective vocabulary can lower prediction difficulty while harming image fidelity.

Tools this method builds on

Section titled “Tools this method builds on”

Vector quantization (VQ) replaces a continuous feature by the nearest entry in a finite codebook. The stored index is discrete; the decoder receives the selected vector. A straight-through estimator supplies a training derivative across the hard choice.

Teacher forcing supplies earlier ground-truth tokens while training a next-token predictor. During free generation those tokens are sampled instead. A training-time reconstruction of teacher-forced predictions is therefore not the same as reconstruction from a full free-running sequence.

LPIPS is a learned perceptual distance: compare normalized pretrained features, weight channel differences, and aggregate across positions and feature levels. In a reconstruction loss its parameters can stay frozen while gradients still pass through it to the reconstructed image.

What changes, and why

Section titled “What changes, and why”

EOSTok jointly trains a 1D semantic tokenizer and causal image generator. IBQ uses softmax/straight-through assignments to connect gradients through quantization. Autoregressive Prediction Reconstruction, or APR, decodes teacher-forced predicted tokens to pixels and applies L2 plus LPIPS. DINOv2 alignment targets spatial hidden features, rather than forcing global latent slots to be pixel locations.

Joint training makes the target itself move

Section titled “Joint training makes the target itself move”

In a two-stage system, the tokenizer fixes the code targets before the prior trains. In EOSTok, the tokenizer and autoregressive generator are optimized together. Changes to the tokenizer change what the generator must predict. This can help match representation to model capacity, but also creates a shortcut: use fewer distinct codes so that next-token prediction becomes easier.

The tokenizer uses one-dimensional latent queries. Image patches attend bidirectionally; queries have causal visibility among themselves and can read image patches, while patch states cannot read query states. These asymmetric masks assign an order to the latent sequence without pretending that its slots form a two-dimensional image grid.

Work through the mechanism

Section titled “Work through the mechanism”

The demo uses two codes that decode to scalar values 0 and 2. A soft probability p gives expected output 2p. Pixel error changes with the predicted probability and produces a gradient. This isolates why reconstruction can supervise a predicted code distribution. It is a teaching relaxation, not the full IBQ estimator or free-running APR training.

Teacher forcing supplies true previous tokens when predicting the next one. APR therefore evaluates predictions under those contexts. It is not an unbiased gradient through a complete freely sampled image trajectory. The distinction matters when interpreting what end-to-end training actually optimizes.

A soft assignment creates a gradient path

Section titled “A soft assignment creates a gradient path”

A hard integer ID blocks ordinary derivatives. The method uses IBQ-style differentiable assignments and replaces pure input lookup to the AR model with assignment probabilities multiplied by an embedding table. A straight-through construction can use a hard choice in the forward pass and a soft derivative in the backward pass. This is a biased gradient estimator; it is not exact differentiation through categorical sampling.

p=softmax⁡(s),pST=sg⁡(onehot⁡(arg⁡max⁡p)−p)+p,u=pSTEp=\operatorname{softmax}(s),\quad p_{\rm ST}=\operatorname{sg}(\operatorname{onehot}(\arg\max p)-p)+p,\quad u=p_{\rm ST}Ep=softmax(s),pST​=sg(onehot(argmaxp)−p)+p,u=pST​E

The equation isolates the hard/soft interface; IBQ has its own full quantization objective. Verify both paths: forward embeddings should match the intended selected codes, while backward gradients should reach the intended encoder/codebook parameters. Simply observing a nonzero gradient is not enough if it reaches an unintended target branch.

APR asks whether predictions still describe the image

Section titled “APR asks whether predictions still describe the image”

Autoregressive prediction reconstruction decodes the predicted token sequence and compares its image with the target through pixel and LPIPS terms. It gives a penalty when codes become easy to predict but no longer reconstruct meaningful content. In the paper this is a teacher-forced prediction path: the prior sees earlier true codes. It is not an unbiased end-to-end gradient through a fully free-running sampled sequence.

LAPR=∥D(z~pred)−x∥22+λpLPIPS⁡(D(z~pred),x)L_{\rm APR}=\|D(\tilde z_{\rm pred})-x\|_2^2+\lambda_p\operatorname{LPIPS}(D(\tilde z_{\rm pred}),x)LAPR​=∥D(z~pred​)−x∥22​+λp​LPIPS(D(z~pred​),x)

For a scalar teaching decoder D(p)=2p and target x, the pixel term is (2p−x)², with derivative 4(2p−x). This gradient tells the predictor how its output affects reconstruction. In the real model, the path crosses assignments, embeddings and the decoder. APR adds a decoder forward and backward path, so joint training cost is not the cost of CE alone.

Training is not sampling

Section titled “Training is not sampling”

In the encoder, image patches interact bidirectionally; queries use causal interaction, can read all patches, and cannot be read back by patches. The tokenizer and generator use learned absolute positions for the 1D latent sequence. APR adds another decoder forward pass, while semantic alignment adds a pretrained teacher dependency.

Monitor information, not just AR accuracy

Section titled “Monitor information, not just AR accuracy”

The reported 50-epoch ablation increases AR accuracy under naive joint training while worsening both reconstruction and generation. APR reverses that failure in the reported setting. Monitor code usage, entropy, reconstruction metrics and generated-image quality together. A larger dictionary can improve reconstruction while making the prior’s task harder; dictionary size and generator capacity interact.

DINOv2 alignment supervises spatial hidden patches and decoder features rather than assigning an invented spatial grid to one-dimensional slots. Tokenizer and generator use learned absolute positions in the described setup. The generator replaces LlamaGen’s two-dimensional RoPE because the latent coordinate meaning changed.

Check asymmetric attention masks, hard-forward/soft-backward assignments, teacher-forcing shifts and APR gradient reach. Log teacher dependencies and guidance method; AutoGuidance is not the same sampling budget as ordinary CFG. The existing reading is paper-level, with no official-code audit, so these are implementation requirements rather than claims that a runnable reproduction is already available.

What this does not establish

Section titled “What this does not establish”

Use the matched 50-epoch ablation below to see the failure of naive joint training. Higher AR accuracy is not sufficient: the easiest codes can give worse images. Main guided results also use AutoGuidance for some sizes, which must not be treated as ordinary CFG with identical cost.

Check your understanding

Section titled “Check your understanding”
Why can AR accuracy rise while image quality falls?

The tokenizer may make its codes less informative and easier to predict. Pixel reconstruction and generated-image metrics test information that token accuracy does not.
