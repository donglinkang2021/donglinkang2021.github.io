ViT: an image becomes a sequence

An interactive field guide

A patch is a group of pixels. A token is the vector used to represent it. ViT makes this interface explicit.

Before this article: Attention and autoregression · Autoencoders

What was already possible

Section titled “What was already possible”

CNNs already learned visual features with shared local filters. Transformers already mixed sequence elements through attention. The question was whether a mostly standard Transformer could learn useful image features at scale.

Tools this method builds on

Section titled “Tools this method builds on”

Self-attention computes a weighted mixture of token values from query–key similarities. A mask determines which tokens can contribute. Position encoding supplies geometry; a causal mask supplies an information boundary. These are separate design choices.

    What changes, and why

    Section titled “What changes, and why”

    ViT divides an image into non-overlapping patches. It flattens each patch, projects it to width D, adds a learned position vector, and applies a bidirectional Transformer encoder. A separate class token feeds the classification head. The new contribution concerns image recognition and scaling, not image reconstruction or autoregression.

    Patch projection is an explicit shape change

    Section titled “Patch projection is an explicit shape change”

    An image is not already a language sequence. Divide H × W pixels into non-overlapping P × P patches, flatten each patch, and apply the same linear map to every patch. The projection learns useful combinations of colors and local pixels. Keeping all projected patches preserves a spatial grid even though the implementation stores a sequence.

    N=HWP2,Xpatch∈RB×N×3P2,Z=XpatchWE+Epos,WE∈R3P2×DN=\frac{HW}{P^2},\quad X_{\rm patch}\in\mathbb R^{B\times N\times3P^2},\quad Z=X_{\rm patch}W_E+E_{\rm pos},\quad W_E\in\mathbb R^{3P^2\times D}N=P2HW​,Xpatch​∈RB×N×3P2,Z=Xpatch​WE​+Epos​,WE​∈R3P2×D

    At 224 × 224 with P=16, N=196. Each RGB patch contains 768 values. A D=768 projection happens to preserve the scalar count at this stage; it is not evidence of a compressed representation. Adding a classification token gives a sequence length of 197. The output head maps the CLS feature to class scores, not pixels.

    Work through the mechanism

    Section titled “Work through the mechanism”

    For a 224 × 224 RGB image and 16 × 16 patches, N=196. Each raw patch has 768 values. A learned matrix maps these to D features. Attention then mixes information across 197 positions, including the class token. N counts positions; D counts features at each position.

    The small grid below uses smaller images. Double the patch side while holding image size fixed. The patch count becomes one quarter. Dense attention scores have N × N entries, so their count becomes one sixteenth. This is a score-matrix estimate, not an end-to-end speed measurement.

    Why attention needs position and normalization

    Section titled “Why attention needs position and normalization”

    Queries ask which information a token needs. Keys describe what a token can provide. Values are the information that will be mixed. For each query, softmax turns query–key scores into weights that sum to one. The square-root scale prevents dot-product magnitude from growing simply because a head has more channels. This explanation concerns the usual variance argument, not a guarantee against every unstable training regime.

    A=softmax⁡ ⁣(QKTdh),Y=AV,Z′=Z+MSA⁡(LN⁡(Z)),Z+=Z′+MLP⁡(LN⁡(Z′))A=\operatorname{softmax}\!\left(\frac{QK^T}{\sqrt{d_h}}\right),\quad Y=AV,\qquad Z^\prime=Z+\operatorname{MSA}(\operatorname{LN}(Z)),\quad Z^+=Z^\prime+\operatorname{MLP}(\operatorname{LN}(Z^\prime))A=softmax(dh​​QKT​),Y=AV,Z′=Z+MSA(LN(Z)),Z+=Z′+MLP(LN(Z′))

    Without positions, swapping two patch tokens swaps their output roles: attention alone does not know which patch was above another. ViT adds learned absolute position vectors before the stack. LayerNorm normalizes channels within each token, not the spatial image. Residual paths retain an identity route while each attention or MLP branch learns a correction.

    For one query with scores (0,0), attention averages the two values. Scores (ln 3,0) give weights (0.75,0.25). With values 2 and 6, the output changes from 4 to 3. This small example isolates mixing. A real head computes its scores and values from learned projections.

    What must change to reconstruct an image

    Section titled “What must change to reconstruct an image”

    A classifier can discard details that do not affect its label. Reconstruction needs outputs at all desired image positions. One option projects each decoded token to 3P² values and rearranges them into pixels. A compressed tokenizer also needs a bottleneck: fewer slots, a narrower grid, quantization, or another explicit constraint. These choices determine what information is lost. Merely flattening the grid does not create TiTok-style latent slots.

    Patch size changes both local representation and attention cost. Halving P at fixed resolution multiplies N by four and the dense attention score count by sixteen. It does not multiply every operation by sixteen; projections and MLPs scale differently. This is why a reconstruction comparison must report resolution, patch size, width and decoder design together.

    # A conceptual pixel head, not the original ViT classifier
patch_pixels = linear(decoded_tokens)  # [B,N,3*P*P]
x_hat = unpatchify(patch_pixels, height=H, width=W)

    Training is not sampling

    Section titled “Training is not sampling”

    Original ViT uses supervised classification. It does not predict the next image token. During higher-resolution fine-tuning, patch size stays fixed and the learned patch-position table is interpolated on its two-dimensional grid. The stored table is a 1D sequence; the interpolation still uses spatial structure.

    Implementation checks and evidence boundary

    Section titled “Implementation checks and evidence boundary”

    Check patch ordering with a coordinate-coded test image. Patchify followed by unpatchify should recover it exactly before learned projections are added. For a resolution change, reshape the learned patch position table to its original two-dimensional grid, interpolate that grid, and keep the CLS position separate. Equal token count does not imply equal grid geometry.

    The original paper trains for recognition. Its objective is not next-token prediction, and its encoder attention is bidirectional. TiTok and RAE supply concrete reconstruction designs; AIM supplies a different autoregressive training objective. Keep these additions explicit when describing a ViT-based autoencoder. The reading here verifies the original paper method, not an audited official training implementation.

    What this does not establish

    Section titled “What this does not establish”

    To reconstruct pixels, add a bottleneck, output queries, a pixel head, and a reconstruction objective. TiTok and RAE make different choices for these parts. Merely replacing a CNN encoder with ViT does not specify a complete autoencoder.

    Check your understanding

    Section titled “Check your understanding”
    Is a continuous patch vector automatically an autoregressive token?

    No. Continuity describes the value space. Autoregression describes a conditional factorization and its training or sampling order.
