VAR：预测下一尺度，而非下一个 patch

交互教程

如果生成器先确定粗略图像，再并行填入更细空间信息呢？VAR 改变了自回归预测的顺序与目标。

前置阅读：VQGAN · VQ-VAE-2 · 注意力与自回归

之前已经能做什么

Section titled “之前已经能做什么”

VQGAN 将网格展平后逐码预测。VQ-VAE-2 已使用粗细网格，但各网格的先验仍逐位置生成。VAR 使用多尺度残差 tokenizer，让 Transformer 一次预测下一尺度的全部位置。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

向量量化（VQ）用有限码本中的最近向量替换连续特征。存储索引是离散的，decoder 接收所选向量；straight-through 为硬选择提供训练导数。

自注意力根据 Q/K 相似度加权混合 token 的 value。Mask 决定哪些 token 可参与，位置编码提供几何，causal mask 提供信息边界；它们是不同设计选择。

码率—失真权衡平衡编码长度与重建误差。较短 token 序列不自动等于较低比特码率，还要考虑码本数、通道宽度与数值精度。表示载荷应与 encoder、decoder 计算分别统计。

改变了什么，为什么

Section titled “改变了什么，为什么”

从编码特征与零重建开始。每个尺度缩放剩余残差、用共享字典量化、上采样并变换选中向量，再累加到重建中。下一残差就是尚未解释的部分。共享码 ID 不代表每尺度具有相同空间含义。

两个模型共享多尺度接口

Section titled “两个模型共享多尺度接口”

VAR 改变先验预测图像离散码的顺序。为此，首先需要产生有效尺度结构的 tokenizer。Tokenizer 仍是卷积编码—量化—解码系统；Transformer 随后在冻结的编码上训练。更好的 next-scale prior 不能恢复 tokenizer 已经丢弃的小文字。

最粗尺度的一个码必须概括大范围内容。细尺度编码前面尺度补偿后剩余的部分。因此每个尺度不是独立缩小的原图，它的目标依赖之前已量化的贡献。所有尺度共享字典，但查码之后还有与尺度相关的残差变换。

逐步理解机制

Section titled “逐步理解机制”

小演示计算边长 1、2、3、4 的网格。公开默认边长为 1、2、3、4、5、6、8、10、13、16，平方和为 680 个码位置。十次尺度预测不等于十个 token；token 数也不独立决定延迟。

Next-scale 分解究竟假设了什么

Section titled “Next-scale 分解究竟假设了什么”

概率链式法则允许固定的分组顺序。VAR 按尺度分组，实际并行预测以更早尺度为条件，同时输出当前尺度全部位置。这是建模选择；tokenizer 非因果并不会让链式法则失效。真正的问题是，尺度分组能否让条件预测更容易，并减少串行步骤。

p(r1:S)=∏s=1Sp(rs∣r<s),Lprior=−∑s∑i=1nslog⁡pθ(rs,i∣r<s)p(r_{1:S})=\prod_{s=1}^S p(r_s\mid r_{<s}),\qquad L_{\rm prior}=-\sum_s\sum_{i=1}^{n_s}\log p_\theta(r_{s,i}\mid r_{<s})p(r1:S​)=s=1∏S​p(rs​∣r<s​),Lprior​=−s∑​i=1∑ns​​logpθ​(rs,i​∣r<s​)

若尺度为 1 × 1、2 × 2 和 4 × 4，共有 21 个 ID，却只有三轮尺度预测。这不意味着只做三次运算：每轮仍执行注意力和大词表投影。比较延迟必须考虑真实 attention mask 与缓存实现，不能只数轮数。

逐步计算残差累计

Section titled “逐步计算残差累计”

令 f 为编码特征，a₀=0 为当前近似。在尺度 s，把残差 f−a 缩放到当前尺度后量化，将所选嵌入放大到最终网格；学习得到的残差变换修正本次贡献，再累加到近似。下一尺度的目标由新的残差计算。

rs=Q(down⁡s(f−as−1)),us=ϕs(up⁡(e[rs])),as=as−1+usr_s=Q(\operatorname{down}_s(f-a_{s-1})),\quad u_s=\phi_s(\operatorname{up}(e[r_s])),\quad a_s=a_{s-1}+u_srs​=Q(downs​(f−as−1​)),us​=ϕs​(up(e[rs​])),as​=as−1​+us​

一个标量例子可检查记账：若 f=1.7，前两次贡献为 1.0 和 0.5，则 a₂=1.5，剩余残差为 0.2。实际贡献是经过插值与卷积的特征图。关键不变量是，解码器使用的累计特征同时决定下一次残差。

approx = zeros_like(features)
for scale in scales:
    ids = nearest_code(downsample(features - approx, scale))
    contribution = residual_transform(upsample(codebook[ids]))
    approx = approx + contribution
x_hat = decoder(approx)

训练与采样的区别

Section titled “训练与采样的区别”

尺度 k 的输入由已累计的粗尺度重建缩放而来。块因果 mask 允许看到截至本尺度的输入，但不暴露本尺度的真实目标码。因此模型可在尺度内部交互，而不读取答案。

训练使用真实粗尺度信息，采样则由先前生成尺度构造。公开 train.py 训练第二阶段并加载 tokenizer，没有提供原始第一阶段的完整配方。代码使用可学习位置与尺度 embedding，而非 RoPE。

先核对 tokenizer，再讨论先验配方

Section titled “先核对 tokenizer，再讨论先验配方”

已核查量化器使用尺度 (1,2,3,4,5,6,8,10,13,16)，平方和为 680 个 ID，而不是 256。Area 下采样和 bicubic 上采样也是行为的一部分。EMA hit 数组统计使用率，不是通过 EMA 更新码本。默认 test_mode 会冻结 tokenizer，训练前必须处理。

检查编码为 ID 再解码得到的累计特征是否与 forward 一致。分别检查编码器、码本和残差变换的梯度。测试未初始化 distributed 的单进程环境。单尺度配置必须明确处理，因为尺度归一化索引可能除以 S−1。

公开训练启动器加载预训练 tokenizer 来训练 prior，并没有提供与论文完全对应的第一阶段训练配方。缺失的 tokenizer 优化器、日程与预处理信息应明确保留为缺失。借鉴 VQGAN 的适配有价值，但要标明适配。训练 prior 时，要确认当前尺度目标不能泄漏到自己的条件中。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

最佳生成指标不是重建指标。VAR 比较还涉及参数量与采样选择。并行预测的依赖结构不同于完全逐码模型，这是设计取舍，而非违背概率链式法则。

检查理解

Section titled “检查理解”
为什么同尺度 attention 在这里不泄漏目标？

输入来自粗尺度重建；真实同尺度 ID 是标签，而非可见输入值。
