MAR：无需码本的自回归

交互教程

自回归规定条件依赖关系，并不要求 token 是整数。

前置阅读：扩散与 Flow Matching · 注意力与自回归 · 评估

之前已经能做什么

Section titled “之前已经能做什么”

类别头预测离散 ID 的概率；直接 L2 回归连续下一 token，对应固定方差高斯模型的条件均值。MAR 用小型条件扩散模型表示每个连续 token 的更丰富分布。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

Flow matching 训练时间条件网络，预测构造的数据／噪声路径上的速度；采样通过多步积分学习场。局部平方误差目标不等于最终随机输出是直接均值回归。

固定方差高斯解释下，直接平方误差预测拟合条件均值。条件分布可能有多个峰，其均值不是逼真样本；diffusion 与 flow head 则学习迭代条件采样过程。

Teacher forcing 在训练 next-token predictor 时提供此前真实 token；自由生成时这些 token 来自采样。因此训练时重建 teacher-forcing 预测，不等于重建完整自由采样序列。

改变了什么，为什么

Section titled “改变了什么，为什么”

首先，Transformer 读取已知 token，为未知位置输出上下文特征；随后 diffusion MLP 以该特征为条件采样 token。论文研究因果 AR 与 masked AR。默认 MAR 按随机顺序分组填充，已知 token 可双向交互，但看不到未知目标真值。

连续 token 仍然有条件概率

Section titled “连续 token 仍然有条件概率”

MAR 使用已有图像 tokenizer 的连续 latent。Transformer 读取已知 token，为未知位置生成上下文特征；条件于这些特征的小型去噪 MLP 建模下一 token 分布。生成目标不重新学习 tokenizer。这个分工把昂贵上下文推理与反复局部去噪分开。

默认 KL-16 在 256² 图像上产生 16 × 16 × 16 表示：256 个位置，每个是 16 维向量。不需要分类词表，但输出 head 仍需表示不确定性。使用连续向量不代表一个确定性回归输出就够了。

逐步理解机制

Section titled “逐步理解机制”

默认 KL-16 tokenizer 将 256² 图像变成 16 × 16 × 16 连续 latent。遮罩位置在编码器前移除，再作为 queries 在解码器恢复。生成顺序随机时，空间位置仍绑定原网格。

演示分开外层生成组与内层去噪步。16 个 token、组大小 4、内层 4 步时，有 4 个外层组和 16 次组内步骤。这些步骤运行小输出头，不一定运行完整 Transformer，因此教学计数不是耗时测量。

噪声预测损失通过加噪目标学习分布

Section titled “噪声预测损失通过加噪目标学习分布”

训练 head 时采样目标 latent z、噪声 ε 和时间 t，构造带噪 token，与上下文 h 一起送入去噪 head。这里允许用 z 构造带噪输入，因为去噪器学习反向过程；但 z 不能作为未遮蔽已知 token 进入上下文 Transformer。这是两条不同的信息边界。

zt=αˉtz+1−αˉtϵ,Lhead=E∥ϵθ(zt,t,h)−ϵ∥2z_t=\sqrt{\bar\alpha_t}z+\sqrt{1-\bar\alpha_t}\epsilon,\quad L_{\rm head}=\mathbb E\|\epsilon_\theta(z_t,t,h)-\epsilon\|^2zt​=αˉt​​z+1−αˉt​​ϵ,Lhead​=E∥ϵθ​(zt​,t,h)−ϵ∥2

干净目标有两个峰时，直接 L2 偏向峰间均值。去噪学习带噪样本如何回到条件数据分布，因此采样从随机噪声开始并重复调用 head。内部链可复用上下文 h，不必每个 head 时间步都重算整个 Transformer。

随机顺序改变可见性，不改变物理位置

Section titled “随机顺序改变可见性，不改变物理位置”

默认 MAR 按随机顺序分组生成。已知位置可双向交互，encoder 排除未知 token 真值；decoder 在未知空间位置插入 queries。位置嵌入仍标识原图位置。随机生成顺序不是随机打乱图像几何。

p(z)=∏gpθ(zGg∣zG<g)p(z)=\prod_g p_\theta(z_{G_g}\mid z_{G_{<g}})p(z)=g∏​pθ​(zGg​​∣zG<g​​)

同组 token 共享可用上下文；并行采样不能被描述为包含严格逐 token AR 的全部组内条件依赖。新生成组加入可见集合后，已有上下文特征也可能改变。不能直接把严格因果语言模型的 KV cache 套到双向上下文计算。

训练与采样的区别

Section titled “训练与采样的区别”

Diffusion Loss 训练输出头对目标 token 去噪，并非直接 L2 预测干净下一 token。固定默认值中，外层 MAR 用 64 轮，输出头用 100 步去噪。单次 token-head 轨迹可复用上下文特征。完成的 latent 网格再由独立图像解码器变为 RGB。

分别统计外层轮次和内部去噪

Section titled “分别统计外层轮次和内部去噪”

已核查默认值包括 70–100% masking、64 个 class buffer tokens、三块宽 1024 的 DiffLoss MLP、1,000 个训练 diffusion timesteps 和 100 个 head 采样步。外层默认 64 轮 MAR。训练时间步数不是推理步数；外层轮数乘 head 步数统计的是小 head 迭代，不是完整 Transformer 调用。

检查 mask 恢复、空间位置与仅在未知目标上计算损失。改变未知干净目标不能改变上下文特征，但可以改变去噪器的带噪训练输入。迁移时移除显式设备假设，保留 tokenizer 缩放。比较不同 tokenizer 时披露重建质量和数据条件；更换 VQ 与 KL tokenizer 不是纯输出损失消融。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

分组预测不具备完全顺序分解的全部组内依赖；双向上下文变化也使严格因果 KV cache 假设不能直接照搬。下列对照改变顺序与注意力，全部收益不能只归因于去除量化。

检查理解

Section titled “检查理解”
去噪平方损失等于直接下一 token 平方误差吗？

不是。去噪器在不同噪声级学习预测，从而定义可采样分布；直接回归从上下文输出一个点估计。
