AToken：连接语义、连续与离散表示

交互教程

统一 tokenizer 不必向每个下游任务提供完全相同的表示层。

前置阅读：RAE · RoPE-ViT · UniTok

之前已经能做什么

Section titled “之前已经能做什么”

语义特征可支持识别，但连续载荷可能很大；压缩 latent 可支持重建；离散 code 则支持类别式生成。AToken 连接这些表示，并将视觉接口扩展到固定尺寸图像之外。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

图文对比学习使匹配图文的嵌入比不匹配图文更相似。它学习与文本的关系，不负责精确像素恢复。冻结文本教师可提供对齐锚点，但仍带来预训练知识。

Gram 矩阵聚合特征通道之间的相关性。比较 Gram 矩阵强调特征统计，可能忽略空间置换。它可补充像素和感知损失，却不能独自约束精确布局或字符身份。

码率—失真权衡平衡编码长度与重建误差。较短 token 序列不自动等于较低比特码率，还要考虑码本数、通道宽度与数值精度。表示载荷应与 encoder、decoder 计算分别统计。

改变了什么，为什么

Section titled “改变了什么，为什么”

从 SigLIP2 视觉塔出发，通过渐进训练引入低维连续 latent 与可选量化。Transformer 使用稀疏坐标 (t,x,y,z) 处理图像、视频及 3D 输入。在新增 4D RoPE 之外保留学习得到的二维绝对位置，以保存预训练空间结构。

一个框架可以提供多种表示层

Section titled “一个框架可以提供多种表示层”

AToken 从 SigLIP2 视觉表征出发，逐步构建低维连续 latent 与可选离散码。这些层的信息预算不同：理解可读取语义特征，重建或生成使用更压缩的接口。不能不检查实验配置，就把一个层级的成绩移到另一个层级。

图像、视频与 3D 观测表示为带 (t,x,y,z) 坐标的稀疏 patches。图像可以位于 t、z 固定的切片，不需要编造时间或深度变化。坐标单位和 patchification 规则决定“位移”的含义。统一接口不代表各模态预处理和输出 heads 相同。

逐步理解机制

Section titled “逐步理解机制”

坐标演示固定图像 x、y 相对位移，改变时间与深度相对位移，观察它们对单个旋转相位的贡献。静态图像可令 t、z 均为零。四个轴描述输入坐标，不代表每张图都有四个非零空间维度。

演示频率为便于计算而选，并非模型参数。真实表示还包含内容与预训练绝对位置，因此 AToken 可说明“加入 RoPE 必须删除所有 APE”并非通则。

四维相位就是坐标与频率的点积

Section titled “四维相位就是坐标与频率的点积”

每个通道对由频率向量和坐标决定旋转角。旋转恒等式使 Q/K 分数依赖坐标差。论文同时保留可学习二维绝对位置，使预训练结构与新增坐标处理共存。这不支持一种位置方法总要替代另一种的规则。

ϕj(p)=ωjTp=ωt,jt+ωx,jx+ωy,jy+ωz,jz\phi_j(p)=\boldsymbol\omega_j^Tp=\omega_{t,j}t+\omega_{x,j}x+\omega_{y,j}y+\omega_{z,j}zϕj​(p)=ωjT​p=ωt,j​t+ωx,j​x+ωy,j​y+ωz,j​z

若图像 token 均为 t=z=0，则只有 x、y 变化。改变坐标尺度会改变相位，除非同时调整频率。复现应保存轴顺序、单位、归一化、token 顺序和通道配对分配。张量形状正确，模型仍可能收到错误几何。

Gram loss 衡量什么

Section titled “Gram loss 衡量什么”

特征重建损失比较对应位置的激活；Gram loss 比较跨位置聚合的通道相关性。F 若有 C 个通道、N 个位置，FFᵀ/N 总结哪些通道常共同激活。这可鼓励纹理统计相近，而不要求每个纹理元素位于相同像素。它不保证文字或物体布局正确。

G(F)=FFTN,LGram=∥G(F(x))−G(F(x^))∥F2G(F)=\frac{FF^T}{N},\qquad L_{\rm Gram}=\|G(F(x))-G(F(\hat x))\|_F^2G(F)=NFFT​,LGram​=∥G(F(x))−G(F(x^))∥F2​

置换特征位置不会改变 FFᵀ，这种不变性同时解释了该统计量的用途与局限。AToken 用感知和 Gram 目标替代对抗训练，但去掉判别器仍然依赖预训练特征。这里的归一化用于解释机制，不冒充已审计代码默认值。

训练与采样的区别

Section titled “训练与采样的区别”

训练使用感知及 Gram 矩阵目标替代对抗训练。Gram 矩阵比较特征相关性，因此可在无需学习判别器的情况下约束纹理统计。无 GAN 仍有感知特征依赖；不同任务也可能读取不同表示阶段。

先固定一个模态与一个接口

Section titled “先固定一个模态与一个接口”

仅做图像实现时，先固定二维切片、encoder 初始化、所选 latent 层与图像 decoder。检查 patch 坐标往返，以及可选量化和连续路径的区别。共同接口验证后再增加模态；渐进课程是方法的一部分，不能随意换成任意混合数据。

现有阅读没有确定可固定的官方复现实现。论文设计与工程提案须分开。比较重建和语义质量时使用同一表示层，并报告预训练依赖。多模态架构图本身不能证明各任务质量相同。
