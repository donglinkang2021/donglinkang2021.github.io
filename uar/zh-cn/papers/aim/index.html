AIM：通过预测 patch 学习特征

交互教程

即使主要评估不是图像生成，连续自回归也可以作为预训练任务。

前置阅读：注意力与自回归 · ViT · 语义表征

之前已经能做什么

Section titled “之前已经能做什么”

ViT 通常读取全部 patch 后分类；语言模型通过预测下一 token 学到有用特征。AIM 将下一 patch 预测用于视觉预训练，目标是连续像素，而非学习得到的离散图像词表。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

自注意力根据 Q/K 相似度加权混合 token 的 value。Mask 决定哪些 token 可参与，位置编码提供几何，causal mask 提供信息边界；它们是不同设计选择。

固定方差高斯解释下，直接平方误差预测拟合条件均值。条件分布可能有多个峰，其均值不是逼真样本；diffusion 与 flow head 则学习迭代条件采样过程。

改变了什么，为什么

Section titled “改变了什么，为什么”

将 patch 按扫描顺序排列并用因果注意力。逐 patch MLP 以平方误差预测下个 patch 的归一化像素。前缀注意力允许初始一组已知 patch 双向交互，仅后续 patch 承担自回归目标。这让主干在下游使用前接触双向上下文。

连续自回归不需要离散码 ID

Section titled “连续自回归不需要离散码 ID”

自回归描述条件顺序，目标可以是连续向量。AIM 按 raster 顺序遍历图像 patches，预测下一个 patch 的归一化像素。较大的逐 patch MLP head 把上下文特征变为预测。主要目标是学习可迁移视觉表征，不是构建高保真随机图像采样器。

P 表示可见 prefix。目标归一化强调 patch 内部变化，而非其绝对均值和尺度。实现时要核查归一化轴与 epsilon；归一化整幅图会定义不同目标。若不移位而预测当前输入 patch，会产生明显信息泄漏。

逐步理解机制

Section titled “逐步理解机制”

演示选择因果模式时，第 i 行可用截至 i 的 keys，其输出预测下个 patch。切换前缀模式，前三个位置可互相读取，后续位置仍保持因果边界。已知前缀像素是输入，不是从未知未来泄漏的目标。

固定高斯输出方差时，最小化平方误差等价于最大化高斯条件似然（相差常数）。若未来有多种可能，最佳平方误差估计可能是它们的均值。即使平均 patch 看起来不好，也仍可能学出有用特征。

平方误差偏向条件均值

Section titled “平方误差偏向条件均值”

固定方差高斯似然的负对数似然等于缩放的平方误差加常数，因此 L2 可理解为拟合条件均值。若下一 patch 的值以相等概率为 −1 或 +1，均值预测返回 0。这有助于学习可预测结构，却可能不是多峰分布中逼真的样本。

MAR 的 diffusion head 用另一种方式处理分布问题：去噪 L2 比较的是在带噪目标条件下的噪声，而不是直接回归干净下一 patch。AIM 的表征结果与 MAR 对直接 L2 生成的负面结果，针对不同成功标准，并不相互否定。

Prefix 提供双向上下文，但不泄漏未来

Section titled “Prefix 提供双向上下文，但不泄漏未来”

可见 prefix 内部可双向注意；其后目标位置仍遵守因果可见性。Prefix 位置不承担 AR 预测目标。这样预训练就接触双向上下文，减轻与下游识别通常看到完整图像之间的不匹配。

五个 patch、两个 prefix 时，前两个可相互混合；预测第四个 patch 可使用此前上下文，但不能看到第四个自身像素或第五个。Mask 必须与输入／目标移位一起测试；三角矩阵正确，标签对齐错误仍会泄漏目标。

关键推导

Section titled “关键推导”

固定方差高斯条件分布的对数似然中，依赖均值的项就是平方误差。平方误差下最佳预测为条件均值，因此点预测可能平均互不兼容的未来。

训练与采样的区别

Section titled “训练与采样的区别”

预训练后丢弃预测头，评估视觉主干。AIM 的 attentive probe 含可训练注意力池化，因此不属于严格线性探针。论文在输入及预测头之前使用正弦绝对位置。

Probe 也是评估协议的一部分

Section titled “Probe 也是评估协议的一部分”

预训练后移除像素预测 head，评估视觉骨干。严格 linear probe 只在固定特征上拟合线性映射；attentive probe 增加可训练注意力池化，容量不同。比较语义准确率前，应报告骨干冻结或微调、池化方式和 probe 架构。

实现检查包括 patch 顺序、prefix 采样、目标归一化、位置相加和掩码损失 reduction。当前阅读侧重方法，不宣称已审计官方代码或恢复完整配方。下游表征成绩应与重建、生成指标分开。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

贡献重点是可扩展表征学习，并未证明直接 L2 预测是逼真生成的最佳分布模型。MAR 发现直接 L2 生成差，不与 AIM 用该目标学到有用特征矛盾。

检查理解

Section titled “检查理解”
注意力探针为何不同于线性探针？

它通过可训练注意力池化改变 patch 特征组合方式；严格线性探针仅在指定固定特征上使用线性读出。
