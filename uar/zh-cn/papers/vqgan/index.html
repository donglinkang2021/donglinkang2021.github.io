VQGAN：保留感知细节的 tokenizer

交互教程

仅追求像素准确可能让重建平滑。VQGAN 将离散瓶颈与感知、对抗训练结合，再用 Transformer 建模编码。

前置阅读：VQ-VAE · 注意力与自回归 · 评估

之前已经能做什么

Section titled “之前已经能做什么”

VQ-VAE 已学习字典与解码器，PixelCNN 类先验建模编码序列。GAN 已用于促进真实图像统计，预训练特征网络也已提供感知距离。VQGAN 将这些工具组成紧凑 tokenizer 与自回归 Transformer 先验。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

向量量化（VQ）用有限码本中的最近向量替换连续特征。存储索引是离散的，decoder 接收所选向量；straight-through 为硬选择提供训练导数。

冻结参数阻止参数更新，不一定阻止对网络输入求导。用于重建图的冻结特征提取器可能仍需要输入梯度；只提供固定目标的 encoder 则可能无需这条路径。

  • 详细解释：vq

改变了什么，为什么

Section titled “改变了什么，为什么”

第一阶段卷积编码器降低空间尺寸，最近码量化保留离散接口。解码器使用像素与 LPIPS 损失，patch 判别器区分真实与重建图像区域。自适应权重可依据解码器末层的重建与对抗梯度作平衡。

阅读顺序从左到右。点击模块，将它与计算和代码对应。代码为教学伪代码；来源链接提供论文方法或已核查的实现。

一个 tokenizer，两种用途

Section titled “一个 tokenizer，两种用途”

先区分重建与生成。重建从已知图像开始：编码器压缩图像，量化器把每个特征换成码本向量，解码器恢复像素。生成从采样的码 ID 开始，复用同一个解码器，却不编码目标图像。Transformer 属于第二种用途。

以 256 × 256 输入、16 倍下采样为例，特征网格有 16 × 16 个位置。若码本有 1,024 项，每个 ID 的定长表示需要 10 bit，256 个 ID 共 2,560 bit，尚未计熵编码与元数据。嵌入维数不是每个 ID 的比特数；这个数值和较低重建损失都不能单独证明生成质量。

逐步理解机制

Section titled “逐步理解机制”

调整信号细节幅度。只有相位与强度匹配目标时，细节才降低配对误差。合理的新振荡不一定是原有细节。该例说明真实感与精确重建需要分开验证，并不模拟 GAN 或 LPIPS 网络。

离散选择为什么还能训练

Section titled “离散选择为什么还能训练”

在一个网格位置，编码器输出向量 zₑ，最近邻搜索返回整数索引 k。argmin 对 zₑ 的精确导数几乎处处为零，在边界还可能不可导，所以不能直接沿这条路径训练编码器。straight-through 在前向保留量化值，反向替换为恒等映射的导数。它是估计器，不是最近邻分配的真实导数。

zST=ze+sg⁡(ek−ze),LVQ=∥sg⁡(ze)−ek∥22+β∥ze−sg⁡(ek)∥22z_{\rm ST}=z_e+\operatorname{sg}(e_k-z_e),\qquad L_{\rm VQ}=\|\operatorname{sg}(z_e)-e_k\|_2^2+\beta\|z_e-\operatorname{sg}(e_k)\|_2^2zST​=ze​+sg(ek​−ze​),LVQ​=∥sg(ze​)−ek​∥22​+β∥ze​−sg(ek​)∥22​

sg 表示停止梯度：保留数值，但导数置零。第一项把选中的码向编码器输出移动，第二项让编码器输出贴近所选码。若标量 zₑ=0.7、eₖ=1，前向值为 1；两项平方距离都是 0.09，却更新不同参数。增大 β 会增强 commitment，不会增加码本容量。

这里写的是通常的目标。已核查的 VectorQuantizer2 在 legacy=True 时保留旧的 β 位置。加载 checkpoint 时须记录这个开关。张量形状相同不代表优化过程相同。

LPIPS：比较特征，而不只比较像素

Section titled “LPIPS：比较特征，而不只比较像素”

L1 比较对应像素值。边缘只移动一个像素，也可能造成很多项增大，虽然物体看起来仍然相近。特征损失先让两幅图经过预训练网络，再比较激活。这改变了“相似”的定义，但不保证判断总是正确：特征可能不重视小文字、精确颜色或训练分布外的细节。

LPIPS 是 Learned Perceptual Image Patch Similarity，其校准来自人类感知比较。只有预训练 backbone 还不构成完整指标。在 VQGAN 实现中，VGG16 提供五个层级的特征；每个空间位置的向量沿通道归一化，平方差经过学习得到的 1 × 1 线性层，在空间上平均，最后跨层求和。

特征层、空间坐标与通道。
a
作用于通道平方差的校准线性权重。

这里的 a 表示实现中的有效权重。LPIPS 论文也把通道乘子写在平方范数内部，其平方起到这里权重的作用。空间平均避免仅因为位置更多就让某层贡献更大；单位长度归一化移除局部比较中的特征幅值；多个层级则组合不同感受野。

在 VQGAN 训练中，这些校准参数被冻结，但损失仍须穿过特征网络，对重建图求导。将参数 requires_grad=False 可以保留这条路径；把重建分支包进 no_grad 则会切断有用梯度。输入缩放同样重要：该实现对处于 tokenizer 图像范围的输入执行固定 scaling layer。

PatchGAN 与两种不同的梯度

Section titled “PatchGAN 与两种不同的梯度”

判别器是一个学习得到的评价网络。PatchGAN 输出分数网格，每个分数通过感受野评价一个区域。它不需要逐个物体的标签，也不逐像素对照原图与重建图。生成器试图提高重建图分数，判别器试图区分真实区域与重建区域。因此，对抗训练产生的细节可能逼真，却不等于原图细节。

LD=12E[max⁡(0,1−D(x))]+12E[max⁡(0,1+D(sg⁡(x^)))],Ladv=−E[D(x^)]L_D=\tfrac12\mathbb E[\max(0,1-D(x))]+\tfrac12\mathbb E[\max(0,1+D(\operatorname{sg}(\hat x)))],\qquad L_{\rm adv}=-\mathbb E[D(\hat x)]LD​=21​E[max(0,1−D(x))]+21​E[max(0,1+D(sg(x^)))],Ladv​=−E[D(x^)]

hinge 的间隔使判别器不再奖励已经越过间隔的正确区域。生成器目标不同，仍希望假图分数更高。生成器步冻结判别器参数但保留输入梯度；判别器步对假图 detach。混淆这些操作会浪费显存，或更新错误的网络。

x_hat = decoder(quantizer(encoder(x)))
# G step: frozen LPIPS and D weights; input gradients remain
loss_g = rec(x, x_hat) + weight * (-D(x_hat).mean()) + loss_vq
# D step: a separate optimizer; stop the image branch
loss_d = hinge(D(x), D(x_hat.detach()))

平衡梯度影响，而不只是损失数值

Section titled “平衡梯度影响，而不只是损失数值”

两个数值相近的损失可以产生很不同的梯度。VQGAN 在解码器末层测量重建项和对抗项的梯度，以范数之比缩放对抗分支。这是局部平衡规则，不能证明每层更新相等，也不能保证 GAN 训练稳定。

λ=sg⁡ ⁣[clip⁡ ⁣(∥∇WLLrec∥2∥∇WLLadv∥2+ε,0,104)]λdisc\lambda=\operatorname{sg}\!\left[\operatorname{clip}\!\left(\frac{\|\nabla_{W_L}L_{\rm rec}\|_2}{\|\nabla_{W_L}L_{\rm adv}\|_2+\varepsilon},0,10^4\right)\right]\lambda_{\rm disc}λ=sg[clip(∥∇WL​​Ladv​∥2​+ε∥∇WL​​Lrec​∥2​​,0,104)]λdisc​

若两类梯度范数为 0.2 和 0.01，未乘额外系数的比值约为 20。若对抗梯度范数增为 0.1，比值降到约 2。对比值 detach 可避免继续通过权重规则本身优化。已核查代码使用 epsilon=1e-4，论文写的是 1e-6；另一个 discriminator factor 在配置的启动步之前关闭对抗项。

训练与采样的区别

Section titled “训练与采样的区别”

判别器与生成器分别更新。判别器步对假图 detach；生成器步冻结判别器参数，但保留其输入梯度。此处 LPIPS 特征固定。tokenizer 之后训练 Transformer 先验，用交叉熵预测移位码 ID。

所读 taming 实现保留 legacy 量化选项，会把 β 放在旧的损失项上；自适应权重 epsilon 也与论文不同。复制配方前要读固定版本，仓库默认值不自动等于论文设置。

这份实现的复现边界

Section titled “这份实现的复现边界”

把代码提交、预处理、checkpoint、优化器状态和损失开关视为一份完整配方。先只检查 tokenizer：编码—查码本—解码的一致性、straight-through 是否向编码器传递非零梯度、LPIPS 参数是否保持不变、判别器步是否不更新解码器。再检查两个优化器和 global step 的恢复。完成这些检查之后，才解释重建评估。

固定版本 imagenet_vqgan.yaml 是一份参考配置：分辨率 256，1,024 × 256 码本，16 倍下采样，base learning rate 为 4.5e-6，每进程 batch 为 12，disc_start 为 250001，disc_weight 为 0.8。启动器还将 base LR 乘以 batch、设备数和累积步数。这些不是所有 VQGAN 的统一设置，也不是 VAR 缺失的 tokenizer 配方。

第二阶段冻结训练后的 tokenizer，把图像转为码 ID。先验使用移位 ID 和交叉熵训练，并检查 causal mask 是否泄漏目标。重建指标应与生成 FID、采样温度及截断设置分开报告。网页演示不会验证这些训练模型的效果。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

对抗训练增加 optimizer、日程和不稳定性。感知上合理的重建可能改变小文字或纹理。论文完整生成质量还包含第二阶段 Transformer 及采样设置，不能只归功于 tokenizer。

检查理解

Section titled “检查理解”
第一阶段重建由 Transformer 生成吗？

不是。tokenizer 使用卷积编解码，Transformer 在第二阶段建模离散码。
