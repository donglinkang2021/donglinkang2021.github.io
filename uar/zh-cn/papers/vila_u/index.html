VILA-U：一套视觉塔，连接理解与生成

交互教程

VILA-U 将离散视觉码接入多模态 next-token 系统，并在每视觉位置内部增加预测深度。

前置阅读：UniTok · 语义表征 · 注意力与自回归

之前已经能做什么

Section titled “之前已经能做什么”

多模态语言模型可读取连续视觉特征，独立图像生成器则使用另一种表示。VILA-U 构造可重建、与文字对齐的离散视觉塔，难点是在学习图像恢复时保持预训练对齐能力。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

残差量化反复量化剩余特征误差，并累加所选向量；它不同于拆分通道后独立查码本，也不同于编码多个空间尺度。必须明确论文中“多个码”的具体含义。

图文对比学习使匹配图文的嵌入比不匹配图文更相似。它学习与文本的关系，不负责精确像素恢复。冻结文本教师可提供对齐锚点，但仍带来预训练知识。

Teacher forcing 在训练 next-token predictor 时提供此前真实 token；自由生成时这些 token 来自采样。因此训练时重建 teacher-forcing 预测，不等于重建完整自由采样序列。

改变了什么，为什么

Section titled “改变了什么，为什么”

视觉与文字组件从预训练 CLIP 类模型初始化。冻结文本塔，以重建及对比目标训练视觉侧。残差量化将高维特征近似为按顺序选择的多个码向量之和。主 LLM 处理空间位置与文字，depth Transformer 处理单个视觉位置内的 codes。

为什么一个位置需要多个残差码

Section titled “为什么一个位置需要多个残差码”

残差量化分阶段近似完整特征。第一个字典捕捉粗略分量，减去后用下一字典量化剩余残差。所有层都处于同一特征空间，最后求和。这不同于 UniTok 的分离通道块，也不同于 VAR 的空间尺度。

r0=z,km=arg⁡min⁡k∥rm−1−ek(m)∥2,rm=rm−1−ekm(m),z^=∑mekm(m)r_0=z,\quad k_m=\arg\min_k\|r_{m-1}-e^{(m)}_k\|^2,\quad r_m=r_{m-1}-e^{(m)}_{k_m},\quad\hat z=\sum_m e^{(m)}_{k_m}r0​=z,km​=argkmin​∥rm−1​−ek(m)​∥2,rm​=rm−1​−ekm​(m)​,z^=m∑​ekm​(m)​

标量 z=1.7 时，第一个码 1.0 留下残差 0.7，第二个码 0.5 留下 0.2，近似为 1.5。后续层细化同一个特征，不代表新像素位置。增加深度会增加载荷和 depth prediction 计算，即使主语言序列长度不变。

逐步理解机制

Section titled “逐步理解机制”

标量演示可选择目标特征与残差级数。每一级从同一微型教学码本选择项，再从剩余误差中减去它。重建特征是所选码之和。不同于 UniTok，后级看到残差，而非另一通道切片。真实 VILA-U 使用学习到的高维向量。

学习重建时维持对齐

Section titled “学习重建时维持对齐”

视觉塔从预训练图文对齐出发。文本塔冻结，视觉组件学习重建并保持对比对齐。这为图像特征的含义提供锚点，而不是要求无约束自编码器从头发现文本对齐空间。重建和对比损失仍然约束特征的不同方面。

论文中这个设置从头训练的困难，不证明联合学习不可能。UniTok 改变了量化、初始化、数据和优化条件。两项结果反映各自完整设置，不是互相矛盾的普遍定律。

统一语言模型中的两条序列轴

Section titled “统一语言模型中的两条序列轴”

主因果模型沿文本和视觉位置推进；到一个视觉位置时，depth model 沿残差层推进。Depth 训练的 teacher forcing 使用此前真实残差 ID，推理必须使用此前采样 ID。这一区别很重要，因为早期残差选择错误会改变后续条件。

图像到文本任务消费视觉嵌入并预测文本；文本到图像任务预测码组并解码为像素。共享 token 和骨干不会消除这些输出接口。成功标准必须包含独立的理解与生成评估。

训练与采样的区别

Section titled “训练与采样的区别”

视觉塔训练后，将多模态 LLM 适配到图文序列。图像理解先读取视觉 codes 再回答文字；图像生成先预测视觉 codes 再解码像素。两者都用 next-token 学习，但主序列与残差码深度是两条不同依赖轴。

应保留的阶段边界与检查

Section titled “应保留的阶段边界与检查”

先验证 tokenizer 的残差重建与文本塔冻结，再在语言模型适配时按配方冻结视觉塔，并检查视觉嵌入如何进入序列。检查主序列和 depth 两层 mask 的目标泄漏。把码组送入 decoder 做 round trip，以发现残差顺序互换或误用拼接。

本页实现指引来自论文方法，现有阅读未审计官方仓库。忠实运行还需要指定初始化、caption 数据、量化器设置与分阶段日程。ImageNet linear probe 不能代替 VQA 或文本条件生成评估。

检查理解

Section titled “检查理解”
depth Transformer 预测什么？

它预测单个视觉位置内部的残差 codes；主 LLM 建模视觉位置和文字 token 间的依赖。
