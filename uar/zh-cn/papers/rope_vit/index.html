RoPE-ViT：让位置进入特征比较

交互教程

绝对位置给 token 加地址；旋转位置改变两个 token 的比较方式。

前置阅读：ViT · 注意力与自回归

之前已经能做什么

Section titled “之前已经能做什么”

ViT 在输入中加入可学习绝对位置编码。序列模型已有 RoPE，通过旋转 query 与 key 编码相对位移。RoPE-ViT 研究如何将其用于两个空间轴。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

自注意力根据 Q/K 相似度加权混合 token 的 value。Mask 决定哪些 token 可参与，位置编码提供几何，causal mask 提供信息边界；它们是不同设计选择。

  • 详细解释：attention

改变了什么，为什么

Section titled “改变了什么，为什么”

将 Q/K 的每对通道视为二维向量，在位置 (x,y) 旋转相位 ωx x + ωy y。Axial RoPE 将通道对分别分配给各轴；mixed RoPE 让同一通道对同时使用两轴并学习频率，从而直接表示斜向频率。这不意味着 axial Transformer 无法识别斜向物体。

(Rϕ(p)q)T(Rϕ(s)k)=qTRϕ(s)−ϕ(p)k(R_{\phi(p)}q)^T(R_{\phi(s)}k)=q^TR_{\phi(s)-\phi(p)}k(Rϕ(p)​q)T(Rϕ(s)​k)=qTRϕ(s)−ϕ(p)​k

位置运算发生在注意力内部

Section titled “位置运算发生在注意力内部”

RoPE 将 head 通道分成一对一对，每对按位置决定的角度旋转。旋转保持向量长度；更重要的是，旋转后的 Q/K 点积与两者角度差有关。这向注意力提供相对位置信息，而不必在 value 流中加入位置向量。

这个恒等式来自 Rᵀφ=R−φ 与旋转角度可相加。若 q=k=(1,0)，分数就是 cos(φs−φp)：角差 0° 得到 1，90° 得到 0，180° 得到 −1。真实模型各通道对有不同频率和内容向量，注意力不是仅由距离的一个余弦决定。

逐步理解机制

Section titled “逐步理解机制”

Q 与 K 都会旋转，其内积取决于两者相位差。两位置平移相同距离，会在相位差中抵消。内容仍然重要：旋转不能取代学习得到的 Q/K 投影。

演示固定 y 相对位移为 2，调整 x 相对位移和频率方向。它只展示一个单位频率通道对。真实注意力头会累加多个不同频率、不同内容的通道对。

Axial 与 mixed 二维频率

Section titled “Axial 与 mixed 二维频率”

视觉 token 有两个坐标。Axial RoPE 把通道对分配给 x 或 y，每对只响应一个轴。Mixed RoPE 为每对分配二维频率向量，相位也能响应斜向位移。这扩展的是相位基底，并不意味着整个 axial Transformer 无法识别斜向物体。

ϕj(x,y)=ωx,jx+ωy,jy,Δϕj=ωx,jΔx+ωy,jΔy\phi_j(x,y)=\omega_{x,j}x+\omega_{y,j}y,\quad \Delta\phi_j=\omega_{x,j}\Delta x+\omega_{y,j}\Delta yϕj​(x,y)=ωx,j​x+ωy,j​y,Δϕj​=ωx,j​Δx+ωy,j​Δy

频率为 (π/2,π/4) 时，向右移动一个 patch 改变 π/2 相位，向下移动一个改变 π/4，联合移动则相加。扩大图像会增加坐标，不需要为旋转部分插值一个固定位置表。但较大坐标仍可能超出训练分布，公式可计算并不保证外推有效。

关键推导

Section titled “关键推导”

旋转矩阵是正交矩阵。Q 上的旋转经过转置后角度变号；两个平面旋转角度相加，因此最终只包含相位差。

Rϕ(p)TRϕ(s)=R−ϕ(p)Rϕ(s)=Rϕ(s)−ϕ(p)R_{\phi(p)}^TR_{\phi(s)}=R_{-\phi(p)}R_{\phi(s)}=R_{\phi(s)-\phi(p)}Rϕ(p)T​Rϕ(s)​=R−ϕ(p)​Rϕ(s)​=Rϕ(s)−ϕ(p)​

线性坐标相位中，共同平移会抵消。这是旋转比较的性质，不能证明完整有限图像网络具有平移不变性。

训练与采样的区别

Section titled “训练与采样的区别”

固定实现不旋转 class token，频率计算使用 float32，mixed 频率可训练。RoPE 在各层注意力内部作用，也可与绝对位置表并存。下列分类证据使用 224²、400 epoch 的 DeiT-III 训练协议。

坐标约定也是模型的一部分

Section titled “坐标约定也是模型的一部分”

已核查实现不旋转 CLS，使用 x=index mod width、y=floor(index/width)。学习到的 mixed 频率不做 weight decay；频率运算先用 float32，再转回 attention 的 dtype。加载权重时必须保留通道配对和 head 维度；换配对方式可能在形状完全合法时改变全部注意力分数。

用小向量检查旋转保范数和相对角度恒等式。测试面积相同的矩形网格，例如 2 × 6 和 3 × 4：只按 token 数缓存会返回错误坐标。形状或设备改变时重建坐标缓存；频率参数变化后，不要复用旧的学习相位。

这里的证据来自识别与密集预测，不能直接证明重建更好。做重建消融时，应固定 tokenizer、数据和训练预算，只改变位置编码。不要为了套用二维 RoPE，就把没有空间锚点的 TiTok slots 人为排成方阵。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

分类分辨率外推不能证明重建或文字渲染更好。网格形状也重要：token 数相同不代表坐标相同。矩形网格的高或宽变化时必须使位置缓存失效。无空间锚点的 TiTok slots 不会因为数量是平方数就具有二维坐标。

检查理解

Section titled “检查理解”
为什么同时旋转 Q 与 K？

成对旋转使比较依赖相位差；仅旋转 Q 会保留绝对相位依赖。
