EOSTok：让预测保留图像信息

交互教程

token 更易预测并不总意味着图像模型更好；tokenizer 可能只是丢弃了信息。

前置阅读：TiTok · 注意力与自回归 · 语义表征

之前已经能做什么

Section titled “之前已经能做什么”

两阶段系统先训练 tokenizer，再在固定 codes 上训练自回归先验。端到端训练可协调两者，但单独 next-token loss 奖励易预测性。码本塌缩或有效词表缩小，可能降低预测难度却损害图像保真度。

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

向量量化（VQ）用有限码本中的最近向量替换连续特征。存储索引是离散的，decoder 接收所选向量；straight-through 为硬选择提供训练导数。

Teacher forcing 在训练 next-token predictor 时提供此前真实 token；自由生成时这些 token 来自采样。因此训练时重建 teacher-forcing 预测，不等于重建完整自由采样序列。

LPIPS 是学习得到的感知距离：比较归一化预训练特征，加权通道差异，再跨位置与层级聚合。作为重建损失时，参数可冻结，但梯度仍通过它传给重建图。

  • 详细解释：lpips

改变了什么，为什么

Section titled “改变了什么，为什么”

EOSTok 联合训练一维语义 tokenizer 与因果图像生成器。IBQ 通过 softmax/straight-through 分配连接量化梯度。自回归预测重建 APR 将 teacher-forcing 下预测的 token 解码成像素，使用 L2 与 LPIPS。DINOv2 对齐施加于空间 hidden features，不强迫全局 latent slots 对应像素位置。

阅读顺序从左到右。点击模块，将它与计算和代码对应。代码为教学伪代码；来源链接提供论文方法或已核查的实现。

联合训练让目标本身也会改变

Section titled “联合训练让目标本身也会改变”

两阶段系统在先验训练前固定 tokenizer 的码目标。EOSTok 联合优化 tokenizer 与 AR generator；tokenizer 改变后，generator 要预测的东西也改变。这可让表示适配模型容量，也产生捷径：减少有效码种类，使 next-token prediction 更容易。

Tokenizer 使用一维 latent queries。图像 patches 双向注意；queries 之间遵守因果顺序并可读取图像 patches，而 patch 状态不能反读 query 状态。这种非对称 mask 为 latent 序列赋予顺序，却不假装 slots 是二维图像网格。

逐步理解机制

Section titled “逐步理解机制”

演示用两个分别解码为 0、2 的 code。软概率 p 给出期望输出 2p；像素误差随预测概率变化，并产生梯度。这分离展示重建如何监督预测码分布，但只是教学松弛，不是完整 IBQ 估计器或自由运行 APR 训练。

Teacher forcing 在预测下一 token 时提供真实前序 token，因此 APR 在这些上下文下评估预测。它不是穿过完整自由采样图像轨迹的无偏梯度。这一区别决定了如何理解端到端训练真正优化的目标。

软分配建立梯度路径

Section titled “软分配建立梯度路径”

硬整数 ID 阻断普通导数。方法采用 IBQ 式可微分配，并把 AR 输入的纯查表换为分配概率乘嵌入表。Straight-through 可在前向使用硬选择、反向使用软导数。这是有偏梯度估计，不是对分类采样精确求导。

p=softmax⁡(s),pST=sg⁡(onehot⁡(arg⁡max⁡p)−p)+p,u=pSTEp=\operatorname{softmax}(s),\quad p_{\rm ST}=\operatorname{sg}(\operatorname{onehot}(\arg\max p)-p)+p,\quad u=p_{\rm ST}Ep=softmax(s),pST​=sg(onehot(argmaxp)−p)+p,u=pST​E

公式隔离硬／软接口，IBQ 还包含完整量化目标。应检查两条路径：前向嵌入是否对应预期选中码，反向梯度是否到达目标 encoder/codebook 参数。仅看到非零梯度不够，因为它也可能走到不该更新的目标分支。

APR 检查预测是否仍描述图像

Section titled “APR 检查预测是否仍描述图像”

Autoregressive prediction reconstruction 把预测 token 序列解码，并通过像素与 LPIPS 项比较目标图像。它惩罚“容易预测却不再包含有效内容”的编码。论文这里使用 teacher-forcing：先验看到此前真实码，而不是对完整自由采样序列进行无偏端到端求导。

LAPR=∥D(z~pred)−x∥22+λpLPIPS⁡(D(z~pred),x)L_{\rm APR}=\|D(\tilde z_{\rm pred})-x\|_2^2+\lambda_p\operatorname{LPIPS}(D(\tilde z_{\rm pred}),x)LAPR​=∥D(z~pred​)−x∥22​+λp​LPIPS(D(z~pred​),x)

标量教学 decoder D(p)=2p 时，像素项为 (2p−x)²，导数为 4(2p−x)。它告诉预测器，输出如何影响重建。真实路径经过分配、嵌入与 decoder。APR 增加 decoder 前后向，联合训练成本不是只有 CE。

训练与采样的区别

Section titled “训练与采样的区别”

编码器中图像 patch 双向交互，queries 因果交互且可读取全部 patch，但 patch 不能反读 queries。一维 latent 序列的 tokenizer 与生成器均用可学习绝对位置。APR 额外增加解码器前向，语义对齐增加预训练教师依赖。

不要只看 AR accuracy，还要看信息是否保留

Section titled “不要只看 AR accuracy，还要看信息是否保留”

报告的 50-epoch 消融中，朴素联合训练提高 AR accuracy，却同时恶化重建和生成；APR 在该设置下缓解问题。应一起监控码使用率、熵、重建与生成质量。更大字典可改善重建，却让先验任务更难，因此字典大小与 generator 容量相互作用。

DINOv2 对齐监督空间 hidden patches 与 decoder 特征，而不是把一维 slots 人为排为空间网格。描述设置的 tokenizer 和 generator 使用学习绝对位置；generator 替换 LlamaGen 二维 RoPE，是因为 latent 坐标含义改变。

检查非对称 mask、硬前向／软反向分配、teacher-forcing 移位和 APR 梯度范围。记录教师依赖与 guidance 方法，AutoGuidance 与普通 CFG 的预算不同。现有阅读停留论文层面、没有官方代码审计，所以这些是实现要求，不是已存在可运行复现的声明。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

用下方匹配的 50-epoch 消融观察朴素联合训练的失败。更高 AR 准确率并不充分，最易预测的 codes 可能给出更差图像。部分大小的主实验采用 AutoGuidance，不能视为成本相同的普通 CFG。

检查理解

Section titled “检查理解”
为什么 AR 准确率上升，图像质量反而下降？

tokenizer 可能让 codes 信息更少、更易预测。像素重建与生成图像指标检验 token 准确率没有覆盖的信息。
