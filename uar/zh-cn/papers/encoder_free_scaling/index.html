Encoder-Free 多模态预训练：去掉视觉编码器之后

交互教程

像素直接进入语言解码器后，视觉计算去了哪里？额外训练成本又可能在何种规模消失？

前置阅读：ViT · CLIP 与 SigLIP 系列 · 多模态模型中的视觉 tokenizer 总览

之前已经能做什么

Section titled “之前已经能做什么”

去掉编码器，究竟去掉了什么？

Section titled “去掉编码器，究竟去掉了什么？”

阅读对象：Lin Chen 等，How Far Are We from Removing the Visual Encoder? Scaling Laws for Encoder-Free Multimodal Pretraining，arXiv:2609.35457v1，2026 年 9 月 28 日。讲解覆盖正文与附录 A–G。

视觉编码器在语言解码器读取图像之前，把 patches 转为带上下文的表示。预训练权重提供视觉先验。Encoder-free 仍保留输入投影，只是把表征学习移入解码器，并没有消除视觉计算。

本文问的是，这种改变如何影响算力分配：新增预算应投入更大的解码器，还是更多训练 token？证据来自受控预训练扫描，而非不同旗舰模型的横向排名。

结论要分成两部分：实测范围内，无编码器的多模态前沿更差；拟合的改善速度更快，因此可以有条件地预测未来追平。第二句话不是已经观察到交点。

相同解码器阶梯，固定规模的视觉编码器

Section titled “相同解码器阶梯，固定规模的视觉编码器”

两组都使用 11 档稀疏 MoE 解码器：非 embedding 总参数 1.1B–44B，激活参数 71M–2.4B。首层是 dense，后续层有 256 个路由专家、top-8 激活及一个共享专家，使用 RMSNorm 与 RoPE。总参数与激活参数反映不同成本。

输入像素、预处理、数据混合与解码器视觉 token 数相同，每个视觉 token 对应 32×32 像素区域。预训练 SigLIP 2 编码器约 400M 参数：27 层、宽度 1152、patch 16、AnyRes。权重与解码器联合训练；固定的是各档实验中的编码器架构规模。

因此，研究隔离的是固定规模视觉先验下的解码器扩展，没有联合优化编码器与解码器规模。两组主方案的 mask 也不同；无编码器因果消融用于检查分配规律是否依然成立。

从预训练视觉特征到解码器 token

Section titled “从预训练视觉特征到解码器 token”

原始像素仍需可训练的输入前端

Section titled “原始像素仍需可训练的输入前端”

无编码器分支把四个相邻 16×16 原始 patches 合成一个 32×32 区域，每个区域含 3072 个像素标量。LayerNorm → linear → LayerNorm 变换该向量，再加上可学习的行、列位置 embedding，最后通过 LayerNorm → RMSNorm → linear 映射到解码器宽度。论文没有给出每个中间宽度，所以下式保留符号 h。

该方案借鉴 Gemma 4 12B Unified 的输入配方，但为对照实验把 3×3 patch 合并改成 2×2。直接照搬原版 48×48 token 覆盖范围会破坏相同 token 数的条件。多个 AnyRes 网格应分别按预处理后的形状计算。

X∈RN×3072→U∈RN×h,Ur,c←Ur,c+er+ec→Z∈RN×dX\in\mathbb R^{N\times3072}\to U\in\mathbb R^{N\times h},\quad U_{r,c}\leftarrow U_{r,c}+e_r+e_c\to Z\in\mathbb R^{N\times d}X∈RN×3072→U∈RN×h,Ur,c​←Ur,c​+er​+ec​→Z∈RN×d
pixels = merge_2x2(raw_patches_16(image))
u = ln2(linear1(ln1(pixels)))
u = u + row_position + column_position
visual = linear2(rmsnorm(ln3(u)))
logits = decoder(interleave(text, visual), image_bidirectional_mask)

IsoFLOP：同一预算应该怎样花？

Section titled “IsoFLOP：同一预算应该怎样花？”

固定 C，选择不同解码器规模 M，为每个规模分配 D=C/M 个 token。模型过小可能受容量限制，模型过大则训练 token 太少。将验证 loss 对 log M 拟合为二次曲线并取最小值；跨预算重复后得到分配规律与 loss 前沿。拟合最小值是估计，不是额外的一次训练。

每个目标使用六个对数间隔预算：文本窗口为 2×10¹⁹–2×10²⁰ FLOPs，多模态为 10²⁰–10²¹。指数描述各模型族内部的增长。归一化交互把各自最小预算时的值设为 1，因此两条线不能比较模型的绝对规模。

先推导最优点，再解释指数

Section titled “先推导最优点，再解释指数”

对可分离近似 L=E+AM⁻ᵅ+BD⁻ᵝ，代入 D=C/M 后对 M 求导。驻点平衡的是两项的边际 loss 贡献，并非要求原始数值相等。求解得到 a=β/(α+β)、b=α/(α+β)、γ=αβ/(α+β)。论文从 IsoFLOP 剖面估计分配指数；这个推导用于理解过度训练分析背后的模型。

αAM−α=βBC−βMβ⇒Mopt=(αAβB)1α+βCβα+β\alpha AM^{-\alpha}=\beta BC^{-\beta}M^\beta\Rightarrow M_{\rm opt}=\left(\frac{\alpha A}{\beta B}\right)^{\frac1{\alpha+\beta}}C^{\frac\beta{\alpha+\beta}}αAM−α=βBC−βMβ⇒Mopt​=(βBαA​)α+β1​Cα+ββ​

更大的多模态 a 表示预算增长时更多增量用于扩展解码器，并非“总 FLOPs 的 57% 用来购买参数”。预算扩大十倍时，a=0.570 对应基准 M 的约 3.72 倍和 D 的约 2.69 倍。

固定模型规模，增加训练 token

Section titled “固定模型规模，增加训练 token”

过度训练从 C_base 对应的最优模型开始，固定 M，将 token 数乘 k，实际计算量为 kC_base。代入可分离 loss 后，可约 loss 项乘上 g(k)。若横轴改为实际计算量，系数应写为 g(k)k^γ；漏掉这一步会误解效率。

理想化推导给出 g(k)=[β+αk⁻ᵝ]/(α+β)。论文实际固定 E、K、γ 后拟合经验系数；k=5 时，无编码器为 0.645，有编码器为 0.692。在最大拟合预算处，报告的多模态 EGᶜ 从 0.62 变为 0.52，EGᴹ 从 0.80 变为 0.74。更多 token 有助于降低 loss，但并未消除无编码器解码器扩容的相对收益。

训练信号与解码协议

Section titled “训练信号与解码协议”

预训练使用 1:1 文本／多模态混合、4096 序列长度、Muon 和 2000 步 warmup。Batch size 与学习率随解码器规模变化，按内部 scaling 规则选择；同档两方案超参数一致。目标是下一文本 token 预测，视觉 token 通过影响文本预测得到梯度。这些信息尚不足以构成完整公开复现配方。

下游评估不增加训练。所有 checkpoint 使用相同 3-shot 示例和提示，每个示例最多 192 个视觉 token，query 最多 768，整段 prompt 最多 4096 个 token。选择题与是非题按答案 likelihood 选取，开放题 greedy 解码最多 32 个 token，不使用外部 OCR。

哪些假设会改变预测？

Section titled “哪些假设会改变预测？”

两组拟合在每个目标上共享下限 E。多模态拟合 E 为 0.403，但跨一个数量级的六个前沿点无法确定真正的渐近下限。将 E 扰动 ±10% 后，k=1 交点移至 [4.8,9.0]×10²¹ FLOPs；这是敏感性范围，不是置信区间。条件 bootstrap 使用 4000 次成对残差重采样；k=5 时保持已有过度训练系数固定。

多模态 2.5 倍预算留出预测的 loss 有符号误差为无编码器 −0.01%、有编码器 +2.19%。这项短距离检查有价值，但没有验证更远交点。固定编码器、MoE 拓扑、混合比例和预处理也限制结论迁移；联合扩大视觉编码器属于另一个分配问题。

按当前训练完整算力口径，附录 C 报告有编码器 a=0.273、γ=0.362，但没有重新拟合该口径下的精确交点。不能把这个指数与仅 decoder 口径的交点混合，称作实测总成本阈值。

检查理解

Section titled “检查理解”
预测约 10²² FLOPs 追平，是否意味着无编码器已经胜出？

不是。多模态主拟合截止于 10²¹ FLOPs，追平是固定编码器规模、共享 loss 下限等条件下的外推。已评估范围内的下游平均分仍落后。
