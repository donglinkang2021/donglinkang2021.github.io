ViT：图像变成序列

交互教程

patch 是一组像素；token 是表示它的向量。ViT 明确建立了这层接口。

前置阅读：注意力与自回归 · 自编码器

之前已经能做什么

Section titled “之前已经能做什么”

CNN 已能用共享局部滤波器学习视觉特征；Transformer 已能用注意力混合序列元素。问题是：基本标准的 Transformer 能否在大规模数据下学习图像特征？

先认识本方法使用的工具

Section titled “先认识本方法使用的工具”

自注意力根据 Q/K 相似度加权混合 token 的 value。Mask 决定哪些 token 可参与，位置编码提供几何，causal mask 提供信息边界；它们是不同设计选择。

    改变了什么，为什么

    Section titled “改变了什么，为什么”

    ViT 将图像切成不重叠的 patch，展开每个 patch 并投影到 D 维，加上可学习位置向量，再输入双向 Transformer 编码器。单独的 class token 进入分类头。贡献围绕图像识别及规模扩展，并非重建或自回归。

    阅读顺序从左到右。点击模块，将它与计算和代码对应。代码为教学伪代码；来源链接提供论文方法或已核查的实现。

    patch 投影

    各 patch 共用投影矩阵，空间混合发生在后面。

    patches = patchify(image, P)
z = patches @ W + bias

    训练状态：原始分类器中可训练的 patch 投影。

    Patch 投影是明确的形状变换

    Section titled “Patch 投影是明确的形状变换”

    图像并不天然是一串语言 token。先将 H × W 像素切成不重叠的 P × P patch，展平每个 patch，再应用同一个线性映射。投影学习颜色和局部像素的组合。即使实现存成序列，只要保留全部 patch，仍保留原来的空间网格关系。

    N=HWP2,Xpatch∈RB×N×3P2,Z=XpatchWE+Epos,WE∈R3P2×DN=\frac{HW}{P^2},\quad X_{\rm patch}\in\mathbb R^{B\times N\times3P^2},\quad Z=X_{\rm patch}W_E+E_{\rm pos},\quad W_E\in\mathbb R^{3P^2\times D}N=P2HW​,Xpatch​∈RB×N×3P2,Z=Xpatch​WE​+Epos​,WE​∈R3P2×D

    224 × 224、P=16 时，N=196，每个 RGB patch 含 768 个数值。若 D=768，此步骤恰好保持标量数，但这不能证明已得到压缩表示。加入分类 token 后，序列长度为 197。输出头把 CLS 特征映射为类别分数，而不是像素。

    逐步理解机制

    Section titled “逐步理解机制”

    224 × 224 RGB 图像采用 16 × 16 patch 时，N=196。每个原始 patch 有 768 个值，经矩阵映射到 D 维特征。注意力在包含 class token 的 197 个位置间混合信息。N 是位置数，D 是每个位置的特征数。

    下方采用更小的教学图像。固定图像尺寸并将 patch 边长翻倍，patch 数变成四分之一。稠密注意力分数有 N × N 项，因此项数变成十六分之一。这是分数矩阵规模估计，并非端到端速度实测。

    注意力为何需要位置与归一化

    Section titled “注意力为何需要位置与归一化”

    Query 表示某个 token 要找什么，key 表示一个 token 可提供什么，value 是将被混合的信息。每个 query 的分数经 softmax 转为和为 1 的权重。除以通道数平方根，可避免点积仅因 head 通道更多就变得更大。这是常用的方差解释，并不保证所有训练条件下都稳定。

    A=softmax⁡ ⁣(QKTdh),Y=AV,Z′=Z+MSA⁡(LN⁡(Z)),Z+=Z′+MLP⁡(LN⁡(Z′))A=\operatorname{softmax}\!\left(\frac{QK^T}{\sqrt{d_h}}\right),\quad Y=AV,\qquad Z^\prime=Z+\operatorname{MSA}(\operatorname{LN}(Z)),\quad Z^+=Z^\prime+\operatorname{MLP}(\operatorname{LN}(Z^\prime))A=softmax(dh​​QKT​),Y=AV,Z′=Z+MSA(LN(Z)),Z+=Z′+MLP(LN(Z′))

    没有位置时，交换两个 patch token 会交换其输出角色；注意力本身不知道哪个 patch 在上方。ViT 在进入堆叠之前加入可学习绝对位置向量。LayerNorm 对每个 token 的通道归一化，不是归一化整幅图像空间。残差路径保留恒等通路，而注意力和 MLP 学习修正量。

    一个 query 的分数若为 (0,0)，就平均两个 value；分数为 (ln 3,0)，权重变为 (0.75,0.25)。若 value 是 2 和 6，输出从 4 变为 3。这个算例隔离了混合机制；真实 head 的分数和值来自学习投影。

    要重建图像，还缺哪些设计

    Section titled “要重建图像，还缺哪些设计”

    分类器可以丢弃不影响标签的细节，重建却需要在全部目标位置产生输出。一种方式是把每个解码 token 投影为 3P² 个数，再重排成像素。压缩 tokenizer 还需要明确瓶颈，如更少 slots、更窄网格或量化。这些选择决定信息如何丢失。只把网格展平，不会得到 TiTok 式 latent slots。

    固定分辨率时，将 P 减半会让 N 增为四倍，稠密注意力分数数量增为十六倍。但不是所有运算都增为十六倍，投影与 MLP 的变化不同。因此比较重建方案时，要同时报告分辨率、patch 大小、宽度和解码器设计。

patch_pixels = linear(decoded_tokens)  # [B,N,3*P*P]
x_hat = unpatchify(patch_pixels, height=H, width=W)

    训练与采样的区别

    Section titled “训练与采样的区别”

    原始 ViT 用监督分类训练，不预测下一个图像 token。高分辨率微调保持 patch 尺寸，并按二维网格插值 patch 位置表。位置表存为一维序列，但插值仍利用空间结构。

    实现检查与证据边界

    Section titled “实现检查与证据边界”

    用坐标编码的测试图检查 patch 顺序。在加入学习投影前，patchify 后 unpatchify 应精确还原。改变分辨率时，应把 patch 位置表还原成原二维网格再插值，并单独处理 CLS 位置。token 数相等不代表网格几何相同。

    原论文训练目标是识别，不是预测下一个 token，encoder attention 也是双向的。TiTok 与 RAE 提供具体重建设计，AIM 则引入不同的自回归训练目标。描述 ViT 自编码器时要明确这些新增部分。本页核查原论文方法，不宣称已审计官方训练实现。

    这些结果不能证明什么

    Section titled “这些结果不能证明什么”

    要重建像素，还须定义瓶颈、输出 query、像素头和重建目标。TiTok 与 RAE 对这些部分有不同设计。仅把 CNN 编码器换成 ViT，不足以定义完整自编码器。

    检查理解

    Section titled “检查理解”
    连续 patch 向量自动意味着自回归 token 吗？

    不是。连续性描述取值空间；自回归描述条件分解及训练或采样顺序。
