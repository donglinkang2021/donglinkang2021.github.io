前置阅读：多模态模型中的视觉 tokenizer 总览 · Qwen3-VL：从图像 patch 到 DeepStack

原生多模态训练仍可以使用视觉编码器

Section titled “原生多模态训练仍可以使用视觉编码器”

官方模型卡描述训练时对多模态 tokens 进行 early fusion。这说明模态何时一起训练，不意味着 encoder-free 架构。同一模型卡明确把模型归类为带视觉编码器的 causal language model。

这里检查 2B、9B、397B-A17B checkpoints。9B 例子包含 27 层、宽 1152 的视觉 Transformer，以及宽 4096 的语言 embeddings；较小 2B 视觉塔为 24 层、宽 1024，输出宽 2048。架构维度不能确定训练数据或初始化 checkpoint。

沿视觉编码器追踪，而非根据文字主干名称猜测

Section titled “沿视觉编码器追踪，而非根据文字主干名称猜测”

视觉路径使用 2×16×16 RGB 时空块、可学习 Conv3d 嵌入、插值绝对位置、空间旋转位置和视觉 Transformer blocks。文字主干组合不同注意力机制，不意味着视觉塔也是线性注意力编码器；应分别检查两个模块。

单图通过时间复制形成一个时间组。公开 processor 复用 Qwen 图像处理实现，其类名可能包含较早的模型名称；这是实现复用，不是该 checkpoint 属于旧模型的证据。

Z=ViT⁡(PatchEmbed⁡(X)+Eabs;Erotary)Z=\operatorname{ViT}(\operatorname{PatchEmbed}(X)+E_{\rm abs};E_{\rm rotary})Z=ViT(PatchEmbed(X)+Eabs​;Erotary​)
z = patch_embed(pixel_values)
z += interpolate_absolute_positions(grid_thw)
for block in vision_blocks:
    z = block(z, rotary_positions)

与 Qwen3-VL 的已核实差异

Section titled “与 Qwen3-VL 的已核实差异”

已检查的三个 Qwen3.5 配置中，deepstack_visual_indexes 均为空。配置本身还不足以证明运行行为，因此继续追踪实现：Qwen3_5VisionModel 返回最终 merger 输出，多模态 forward 将它写入输入位置；没有返回 Qwen3-VL 的 DeepStack 特征列表，也没有在早期 LLM block 后加入这些特征。

这是针对固定 checkpoints 和实现的代码观察，不证明去掉 DeepStack 导致任何报告的质量提升。两个家族的语言模型、数据和训练也不同；因果结论需要匹配消融。

# Inspected Qwen3.5 path
vision = visual(pixel_values, grid_thw)
llm_input[image_positions] = vision.pooler_output
# No intermediate DeepStack additions in this path.

Merger 连接视觉宽度与语言宽度

Section titled “Merger 连接视觉宽度与语言宽度”

最终 merger 执行 LayerNorm、空间 2×2 分组与 GELU MLP。已调整 512×512 图像的 1024×1152 编码器特征，先成为 256×4608 的拼接向量，再成为 256×4096 的语言宽度特征。拼接先把四个向量保留为不同坐标，然后才做可学习投影。

视觉向量通过 mask 替换 image 占位 embeddings。因此重复的占位 ID 标记位置，具体图像内容由写入的向量携带。已检查路径中没有最近邻码本查找。

[1024,1152]→[256,4⋅1152]→[256,4096][1024,1152]\rightarrow[256,4\cdot1152]\rightarrow[256,4096][1024,1152]→[256,4⋅1152]→[256,4096]
merged = vision_output.pooler_output
image_mask = locate_image_placeholders(input_ids)
inputs_embeds = inputs_embeds.masked_scatter(image_mask, merged)

重建实验还需要什么

Section titled “重建实验还需要什么”

Early fusion 不会自动产生像素解码器。重建研究必须选择 merger 前或后的特征，定义 decoder 如何处理其空间布局，再用图像目标训练。文字生成成功不是重建指标。

计算器用于检查序列和宽度变化，包括视频末帧复制；它只计算形状，不能给 Qwen3.5 与 Qwen3-VL 排名、估计缺失的训练成本，或预测 merger 保留了多少像素细节。
