Gemma 4：视觉编码器、池化与 encoder-free 分支

交互教程

比较五种型号，同时保留 12B 在架构上的关键差异。

前置阅读：多模态模型中的视觉 tokenizer 总览

之前已经能做什么

Section titled “之前已经能做什么”

一个家族，三种视觉配置

Section titled “一个家族，三种视觉配置”

E2B 与 E4B 使用约 150M 的视觉编码器，16 层、宽 768；31B 与 26B-A4B 使用约 550M 编码器，27 层、宽 1152；12B 则去掉独立视觉 Transformer。把五种型号概括成一个视觉 tokenizer，会隐藏主要架构差异。

文字词表约有 262K 项，这是文字 tokenizer 的属性，不是视觉码字数量。同样，为紧凑权重进行量化感知训练，不意味着图像表示采用离散 VQ 码本。

改变了什么，为什么

Section titled “改变了什么，为什么”

先编码小 patch，再做空间平均

编码器分支采用 16×16 RGB patches。可学习投影与二维绝对位置送入带 axial 2D rotary 的双向视觉 Transformer blocks。完成图像范围内的处理后，对 3×3 空间特征分组平均，再归一化/缩放并投影到语言宽度。

z = vision_transformer(patches16, positions_xy)
z = spatial_average_pool(z, kernel=3)
valid_z = remove_padding(z, valid_mask)
visual = language_projection(valid_z)

Token 预算是上限，不是精确输出数

支持的图像预算为 70、140、280、560、1120 个 soft tokens。设池化后空间单位 m=16×3=48 像素，理想目标面积为预算×48²。两边同时乘以“目标面积除以原面积”的平方根，再分别向下取 48 的倍数。

H2, W2 = aspect_ratio_resize(H, W, max_soft_tokens=B)
patch_count = (H2 // 16) * (W2 // 16)
valid_soft_tokens = patch_count // 9

训练状态：静态实现审计；训练状态见下文。

f=B(48)2HW,H′=48⌊fH48⌋,W′=48⌊fW48⌋,N=H′W′482≤Bf=\sqrt{\frac{B(48)^2}{HW}},\quad H^\prime=48\left\lfloor\frac{fH}{48}\right\rfloor,\quad W^\prime=48\left\lfloor\frac{fW}{48}\right\rfloor,\quad N=\frac{H^\prime W^\prime}{48^2}\le Bf=HWB(48)2​​,H′=48⌊48fH​⌋,W′=48⌊48fW​⌋,N=482H′W′​≤B

12B 直接投影大像素块，不经过独立视觉塔

12B 模型每个像素块接收 48×48×3=6912 个值，并使用轻量嵌入路径。配置仍写有 processor patch_size=16、pooling_kernel_size=3，但 model_patch_size=48。Processor 把 3×3 小像素块重新排列为大块；重排像素不等于平均编码后的特征。

z = ln2(dense(ln1(raw48)))
z = ln3(z + position_x + position_y)

当前型号的固定配置

有效 token 不包括 padding 槽、图片边界、换行、时间戳文字或其他文本。视频模式不执行抽帧和视频预算分配：输入边长必须是 Qwen 的 32 或 Gemma 的 48 的倍数。单图的帧复制是时空 patch 接口操作，不意味着有运动信息。

训练与推理

Section titled “训练与推理”

按各自训练条件比较路径

Section titled “按各自训练条件比较路径”

报告说明独立视觉编码器在预训练中冻结，而 encoder-free 12B 从头训练。公开推理类本身不保证历史 optimizer 调度，复现需要明确参数组及对应训练配方。

两条路线都出现 48 像素输出单位：一条先让小 patches 在预训练视觉塔中交互再池化，另一条让语言主干处理直接投影的大像素块。相同输出数不等于相同视觉计算或细节保留。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

哪些信息仍未知或不在本次比较内

Section titled “哪些信息仍未知或不在本次比较内”

已检查报告不足以为所有编码器分支指定某个精确 SigLIP 初始化 checkpoint，因此保留未知。比较涉及视觉输入与文字输出，不是图像解码器；音频与多 token 预测不在本页审计范围内。

用于重建研究时，应区分池化前 patch 特征、池化后特征和 encoder-free 投影块。它们的训练历史与空间接口不同，基于其中任意一种训练像素 decoder 都是独立实验。

检查理解

Section titled “检查理解”
Processor 的 patch_size=16 能证明 Gemma 4 12B 有 patch-16 视觉 Transformer 吗？

不能。Processor 将像素重排为 48×48 块，模型使用无独立视觉塔的投影路径。
