交互教程

追踪像素如何进入语言模型，并区分这种接口与图像编解码器。

前置阅读：ViT · 语义表征 · Vision Transformers Need Registers：给 ViT 增加内部计算位置

图像 token 的三种含义

Section titled “图像 token 的三种含义”

在 VQ 自编码器中，图像 token 常指码本索引；在 ViT 中，它通常是连续特征向量；在 LLM 输入中，image 占位 ID 标记将要写入视觉向量的位置。这个占位 ID 本身并不是编码图像内容的视觉词表项。

广义 visual tokenizer 可以指整条输入路径：调整尺寸、切分像素、编码特征、减少位置、对齐维度。重建 tokenizer 还需要像素解码器与相应目标。能够回答图像问题的模型，不会因此自动提供这个解码器。

相近的 token 数可以隐藏不同计算

Section titled “相近的 token 数可以隐藏不同计算”

Qwen3-VL 和 Qwen3.5 使用可学习 merger：拼接四个相邻特征向量，再经过 MLP。Gemma 4 编码器分支对九个编码后的空间位置求平均。Gemma 4 12B 直接嵌入更大的像素块。这些操作在减少位置前混合了不同的信息。

Qwen3-VL 向三个早期 LLM 层加入中间视觉特征；已审计 Qwen3.5 实现的输入路径仅使用最终合并视觉输出。Gemma 4 应分成小编码器、大编码器和 encoder-free 分支。下表采用具体 checkpoint revision，不以家族名称猜测结构。

当前型号的固定配置

有效 token 不包括 padding 槽、图片边界、换行、时间戳文字或其他文本。视频模式不执行抽帧和视频预算分配：输入边长必须是 Qwen 的 32 或 Gemma 的 48 的倍数。单图的帧复制是时空 patch 接口操作，不意味着有运动信息。

训练与推理

Section titled “训练与推理”

为何必须看预训练目标

Section titled “为何必须看预训练目标”

CLIP 使用图文对比匹配，SigLIP 使用基于 sigmoid 的成对目标，SigLIP-2 又扩展训练配方。DINO 类方法使用不同图像视图间的自蒸馏。这些目标能产生有用语义特征，但不明确要求恢复每个像素。

多模态文字训练可按不同阶段更新连接器、编码器和 LLM。冻结编码器仍计算特征，其输入梯度也可能存在。Early-fusion 训练不意味着架构没有编码器；部署时量化权重也不意味着连续视觉特征变成 VQ codes。

Section titled “这些结果不能证明什么”

哪些设计可以迁入重建研究

Section titled “哪些设计可以迁入重建研究”

对 UAR，一个有意义的实验是固定某个编码器，分别使用 merger 前后特征训练解码器，保持图像数据和 decoder 容量一致，分别测量重建、语义和成本。这是建议实验，不是三个模型家族已报告的结论。

本综述是 2026-11-03 核对的快照，聚焦指定家族，不拼接不可比榜单、不推断缺失的视觉预训练配方，也不替换当前 VAR 优先路线。

检查理解

Section titled “检查理解”
视觉 token 数相同，是否意味着压缩程度或质量相同？

不意味着。特征宽度、输入分辨率、表征类型、训练与下游用途都可能不同。
