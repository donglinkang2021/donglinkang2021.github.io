Qwen3-VL：从图像 patch 到 DeepStack

交互教程

追踪一张图像经过视觉编码器、空间 merger 和三次残差特征注入。

前置阅读：多模态模型中的视觉 tokenizer 总览 · RoPE-ViT · CLIP 与 SigLIP 系列

之前已经能做什么

Section titled “之前已经能做什么”

语义编码器还需要语言接口

Section titled “语义编码器还需要语言接口”

预训练视觉编码器可为每个 patch 返回一个连续特征；语言模型需要自身隐藏宽度的向量，以及可处理的序列长度。Merger 负责这些接口差异。它不是图像解码器，也不选择离散图像词表项。

报告从 SigLIP-2 checkpoints 出发继续动态分辨率训练。默认使用 SO-400M 系列，小型 2B/4B 语言模型使用 SigLIP2-Large。把结果叫作未变动的冻结 SigLIP-2，会漏掉这段继续训练。

像素变成动态空间网格

Section titled “像素变成动态空间网格”

8B checkpoint 使用 27 层、宽 1152 的视觉编码器，空间 patch 边长 16、时间 patch 大小 2、空间合并边长 2。图像 processor 在像素面积限制下，把两边调整成 32 的倍数。单图通过重复输入帧满足时间 patch 接口，并未增加新的观测。

可学习 Conv3d 把每个 2×16×16 RGB 块映射为视觉向量。插值绝对位置嵌入与视觉二维旋转嵌入提供空间结构；语言主干另用 interleaved MRoPE。它们属于不同阶段的位置机制。

DeepStack 加特征，不追加位置

Section titled “DeepStack 加特征，不追加位置”

8B 视觉 block 索引 [8,16,24] 从零开始。专用 merger 把这些中间特征映射为 LLM 宽度向量；前三个语言 block 各自结束后，在视觉位置加入一组特征，文字位置不接受这次直接加法。

这是残差特征注入，不是对独立图像记忆做 cross-attention。最终合并特征已经提供初始视觉 embeddings，后续再加三组特征，不会把图像序列长度乘四。2B 改选 [5,11,17]，所以层索引必须读取对应配置。

Section titled “对照作者 Figure 1”

沿图像或视频 patch 经视觉编码器、空间 merger 进入语言模型的位置。DeepStack 另将中间视觉特征送入早期语言层；这是在既有视觉位置上的残差加法，不是额外 cross-attention 模块，也不是追加三条 token 序列。

逐步理解机制

Section titled “逐步理解机制”

四个空间向量变成一个语言宽度向量

Section titled “四个空间向量变成一个语言宽度向量”

对主 merger，先归一化视觉向量，再拼接每个空间 2×2 分组，经两层 MLP 返回 LLM 宽度。已调整的 512×512 像素对应 1024 个编码器位置，合并成 256 个向量；每个向量先为 4×1152=4608 维，再投影到 8B 的 4096 维。

Processor 会安排 patch 顺序，使相邻位置正确成组。直接 reshape 任意 raster 序列可能组合错误位置。该操作是可学习特征压缩，不是平均池化，也不是最近码字选择。

group = spatially_group(norm(z), side=2)
merged = fc2(gelu(fc1(group)))
inputs_embeds[image_mask] = merged

当前型号的固定配置

有效 token 不包括 padding 槽、图片边界、换行、时间戳文字或其他文本。视频模式不执行抽帧和视频预算分配：输入边长必须是 Qwen 的 32 或 Gemma 的 48 的倍数。单图的帧复制是时空 patch 接口操作，不意味着有运动信息。

训练与推理

Section titled “训练与推理”

区分训练阶段与消融设置

Section titled “区分训练阶段与消融设置”

报告描述先仅更新 merger 的对齐阶段，再进行全部参数的更长上下文预训练。DeepStack 消融采用内部 15B-A2B 模型、200B tokens、无后训练；平均分 74.7→76.0，DocVQA 89.5→91.1。这些不是公开 8B checkpoint 的分数。

视频还涉及抽帧、空间调整、时间分组和文字时间戳。计算器从已采样、已调整尺寸的视频帧开始。三帧输入时间大小为二的编码器时，重复最后一帧得到两个时间组；时间戳文字成本不计入该数。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

视觉输入路径没有提供什么

Section titled “视觉输入路径没有提供什么”

这些连续特征服务于文字生成与视觉推理，已审计路径没有像素解码器或 VQ 码本。用于重建时，还需选择特征层、训练解码器，并把重建与 VQA 分开评估。

报告与当前实现分别固定为两份证据，未记录的训练细节保留未知。型号选择器展示已检查的配置差异，不声称名称相近的 checkpoints 共用相同权重。

检查理解

Section titled “检查理解”
DeepStack 会让视觉上下文长度变成三倍吗？

不会。它在早期 LLM 层已有的视觉位置上相加特征。
