生成模型的基本语言

交互教程

生成器需要从许多可能图像中作出选择。学习网络之前，先区分数值、分布和条件分布。

之前已经能做什么

Section titled “之前已经能做什么”

张量是具有形状的数组。B 是样本数，C 是通道数，H、W 是图像高宽。图像批次常用 [B,C,H,W]，序列常用 [B,N,D]，即 N 个位置、每位置 D 个数。token 可以是整数 ID，也可以是向量。

改变了什么，为什么

Section titled “改变了什么，为什么”

latent z 是内部表征。编码器把观测图像 x 映射到 z，解码器把 z 映射回图像或图像分布。先验描述观察 x 之前模型认为哪些 z 可能出现。重建从已有图像出发，生成可以从先验采样出发。

先读轴，再数 token

Section titled “先读轴，再数 token”

张量是带索引的数组。[B,C,H,W] 中，B 为样本，C 为通道，H、W 为像素位置；[B,N,D] 中，N 为 token，D 为特征通道。Reshape 可改变索引而不丢任何值。压缩需要信息约束，不能只看形状变短。

32×32 位置、16 通道的网格每样本含 16,384 个值；把 2×2 邻域移入通道后得到 16×16 位置、64 通道，仍有 16,384 个值。离散码应统计 ID 和词表比特。连续标量若未指定精度或编码模型，就没有固定信息码率。

32⋅32⋅16=16⋅16⋅64,Bfixed code=N⌈log⁡2K⌉32\cdot32\cdot16=16\cdot16\cdot64,\qquad B_{\rm fixed\ code}=N\lceil\log_2K\rceil32⋅32⋅16=16⋅16⋅64,Bfixed code​=N⌈log2​K⌉

逐步理解机制

Section titled “逐步理解机制”

调整两个二元概率。若 P(第一个=1)=0.6，P(第二个=1|第一个=1)=0.7，则联合事件概率为 0.42。第一个为 1、第二个为 0 的概率为 0.18，两者之和为 0.6。条件分布本身仍须归一化。

链式法则不假设位置独立，只是选定联合分布的书写顺序。因果模型借助 mask 学习条件分布。连续变量使用密度而非精确取值的概率，密度不必小于 1。

期望是对不确定性的平均

Section titled “期望是对不确定性的平均”

期望按概率加权平均可能结果，不等于采样一个结果。若变量等概率为 −1 或 +1，均值为 0，尽管 0 从不出现。这解释直接平方误差预测为何会模糊歧义目标，也解释生成 head 为何需要建模分布。

E[X]=∑xp(x)x,E[(X−a)2]=Var⁡(X)+(E[X]−a)2\mathbb E[X]=\sum_xp(x)x,\qquad \mathbb E[(X-a)^2]=\operatorname{Var}(X)+(\mathbb E[X]-a)^2E[X]=x∑​p(x)x,E[(X−a)2]=Var(X)+(E[X]−a)2

训练与采样的区别

Section titled “训练与采样的区别”

loss 是训练目标，不自动等于图像质量。负对数似然奖励模型分配给观测数据的概率。平方误差仅在指定方差假设下对应高斯似然。按像素求和或平均会改变其尺度。

这些结果不能证明什么

Section titled “这些结果不能证明什么”

更小的张量不一定是更好的表征。需要同时考虑位置数、通道数、精度和下游模型成本。256 个整数码与 256 个向量并不包含相同信息。

检查理解

Section titled “检查理解”
连续 token 本身就是概率分布吗？

不是，它是一个值。模型还需描述各种可能取值的分布。
