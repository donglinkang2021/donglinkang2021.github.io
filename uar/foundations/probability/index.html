A small language for generative models

An interactive field guide

A generator must choose among many possible images. Before studying its network, separate a value, a distribution, and a conditional distribution.

What was already possible

Section titled “What was already possible”

A tensor is an array with a shape. B is the number of examples, C the number of channels, and H and W the image height and width. An image batch often has shape [B,C,H,W]. A sequence often has shape [B,N,D]: N positions, D numbers at each position. A token can be an integer ID or a vector.

What changes, and why

Section titled “What changes, and why”

A latent z is an internal representation. An encoder maps an observed image x into z. A decoder maps z back to an image or to a distribution over images. A prior describes which z values the model expects before it sees x. Reconstruction starts from an observed image; generation may start from a prior sample.

Read axes before counting tokens

Section titled “Read axes before counting tokens”

A tensor is an indexed array. In [B,C,H,W], B indexes examples, C channels and H,W pixel positions. In [B,N,D], N indexes tokens and D their feature channels. A reshape can change the indexing without discarding any values. Compression needs an information constraint, not merely a shorter-looking shape.

If a grid has 32×32 positions and 16 channels, it contains 16,384 values per example. Grouping 2×2 neighbours into channels gives 16×16 positions and 64 channels: still 16,384 values. For discrete codes, count IDs and vocabulary bits instead. A continuous scalar has no fixed information rate until precision or a coding model is specified.

Work through the mechanism

Section titled “Work through the mechanism”

Use the controls to change two binary probabilities. If P(first=1)=0.6 and P(second=1|first=1)=0.7, the joint event has probability 0.42. The remaining event with first=1 has probability 0.18. These add to 0.6. The conditional distribution must still sum to one.

The chain rule does not assume that positions are independent. It only chooses an order for writing the joint distribution. A causal model learns these conditional distributions with a mask. Continuous variables use densities rather than probabilities of exact values; their densities need not be less than one.

An expectation is an average over uncertainty

Section titled “An expectation is an average over uncertainty”

An expectation averages over possible outcomes, weighted by probability. It is not the same as sampling one outcome. If a variable is equally likely to be −1 or +1, its mean is zero, although zero never occurs. This difference explains why direct squared-error prediction can blur ambiguous targets and why a generative head models a distribution.

Training is not sampling

Section titled “Training is not sampling”

A loss is a training objective, not automatically a measure of image quality. Negative log-likelihood rewards probability assigned to observed data. Squared error corresponds to a Gaussian likelihood only with stated variance assumptions. Averaging over pixels versus summing changes its scale.

What this does not establish

Section titled “What this does not establish”

A smaller tensor is not necessarily a better representation. Count positions, channels, precision, and the cost of the model that consumes them. Do not compare 256 integer codes with 256 vectors as if both carry the same information.

Check your understanding

Section titled “Check your understanding”
Is a continuous token already a probability distribution?

No. It is a value. A model must separately define how possible values are distributed.
