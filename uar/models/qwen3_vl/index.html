An interactive field guide

Trace one image through the vision encoder, spatial merger and three residual feature injections.

What was already possible

Section titled “What was already possible”

A semantic encoder needs a language interface

Section titled “A semantic encoder needs a language interface”

A pretrained visual encoder can return one continuous feature per patch. A language model expects vectors of its own hidden width and a manageable sequence length. A merger handles these interface differences. It is not an image decoder and does not select discrete image vocabulary entries.

The report starts from SigLIP-2 checkpoints and continues training at dynamic resolutions. SO-400M is the default encoder family; smaller 2B/4B language models use SigLIP2-Large. Calling the result an unchanged frozen SigLIP-2 would miss this continued training.

Pixels become a dynamic spatial grid

Section titled “Pixels become a dynamic spatial grid”

The 8B checkpoint uses a 27-block vision encoder of width 1152. Its spatial patch side is 16, temporal patch size is 2 and spatial merge side is 2. The image processor adjusts both sides to multiples of 32 under pixel-area limits. For a still image, repeated input frames satisfy the temporal patch interface; they do not add new observations.

A learned Conv3d maps each 2×16×16 RGB block to a visual vector. Interpolated absolute position embeddings and visual 2D rotary embeddings supply spatial structure. The language backbone separately uses interleaved MRoPE. These position mechanisms belong to different stages.

DeepStack adds features without appending positions

Section titled “DeepStack adds features without appending positions”

The 8B visual block indices [8,16,24] are zero-based. Dedicated mergers turn those intermediate features into LLM-width vectors. After each of the first three language blocks, one feature set is added at visual positions only. Text positions do not receive that direct addition.

This is a residual feature injection, not cross-attention to a separate image memory. The final merged features already supplied the initial visual embeddings. Adding three feature sets later does not multiply the image sequence length by four. The 2B model instead selects [5,11,17], so layer indices must come from its own configuration.

Work through the mechanism

Section titled “Work through the mechanism”

Four spatial vectors become one language-width vector

Section titled “Four spatial vectors become one language-width vector”

The main merger normalizes visual vectors, concatenates each spatial 2×2 group, applies a two-layer MLP and returns the LLM width. For 512×512 prepared pixels, the encoder processes 1024 patch positions. The merger packs them into 256 vectors, each initially 4×1152=4608 wide, then projects to 4096 for 8B.

The processor orders patches so that these neighbors are grouped correctly. A naive reshape of an arbitrary raster sequence can group the wrong locations. The operation is learned compression of features, not average pooling and not nearest-code selection.

Training and inference

Section titled “Training and inference”

Separate the training stages and the ablation setting

Section titled “Separate the training stages and the ablation setting”

The report describes an alignment stage that updates only merger layers, then full-parameter pretraining with longer contexts. Its DeepStack ablation uses an internal 15B-A2B model trained on 200B tokens, without post-training. The reported average changes from 74.7 to 76.0 and DocVQA from 89.5 to 91.1. These are not scores for the public 8B checkpoint.

For video, frame sampling, spatial resizing, temporal grouping and textual timestamps all matter. The calculator starts from already sampled and resized video frames. If three frames enter a temporal-size-two encoder, repeating the last frame yields two time groups. Timestamp text costs remain outside its count.

What this does not establish

Section titled “What this does not establish”

What the visual path does not supply

Section titled “What the visual path does not supply”

These continuous features feed text generation and visual reasoning. The audited path has no pixel decoder and no VQ codebook. Reusing it for reconstruction would require choosing a feature layer and training a decoder, then evaluating reconstruction separately from VQA.

The report and current implementation are separately pinned evidence. Undocumented training details remain unknown. The model-family selector below shows inspected configuration differences; it does not claim all similarly named checkpoints share identical weights.
